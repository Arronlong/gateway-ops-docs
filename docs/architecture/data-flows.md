# 主要数据流

本页说明数据如何进入页面，以及哪些环节会写入远端。按问题查找公式与边界可使用 [业务规则总览](/logic/index)。

## 渠道采集

```text
渠道配置与监控开关 → 调度 / 手动完整同步 → 认证与连接器
→ 余额、分组倍率、支持的使用记录 → 当前值、历史采样和变化日志
→ 事件策略与通知 → 页面查询与趋势
```

自动扫描跳过暂停渠道，手动同步可以包含。多账号部分失败时余额可暂用旧值；手工渠道不登录上游读数据。调用记录回填与水位见 [渠道余额与调用记录](/logic/channel-consumption)。

## 中转站快照与倍率

```text
Sub2API 管理 API / New API 管理凭据
→ 平台适配器 → 账号、渠道、组、用户及可读取遥测
→ 本地快照保存 → 关联协调 → 自动调组 → 自动优先级
```

New API 将渠道适配为统一账号，并对不支持的并发、池重试或成本探测能力明确留空 / 拒绝；不能把跨平台统一界面理解为上游字段等价。详细边界见 [New API 中转站规则](/logic/newapi-relay)。

```text
倍率同步 → 批量上游计费探测 → 保存有效成本与观察时间
→ 渠道关联协调 → 自动调组
```

两种触发都有局部策略开关；自动优先级只在快照路径执行。遥测读取失败可保留旧事实，策略失败不会整体回滚已经完成的远端修改。详见 [同步与数据处理](/logic/synchronization)。

## 统计与成本

```text
账本 → 区间收入支出
渠道快照 → 当前余额与推算消耗
Sub2API 全站用量 → 自动用户收入
账号区间用量 + 当前有效成本来源 → 调用成本与完整性
```

页面并列展示这些来源，不把余额消耗与调用成本再相加。消费趋势使用逐条历史成本字段，区间成本可按当前覆盖重算；具体公式见 [成本与倍率](/logic/cost-accounting) 和 [指标口径](/logic/metrics)。

```text
渠道 / Sub2API 账号近期样本 → 统一时间窗与最多 60 条筛选
→ 缓存 Token 聚合 + 实际尝试结果 → 环形指标 / 排序 / 四项综合评分
```

此评分由成功率、稳定性、缓存命中和延迟组成；缺任一项时不输出总分。统计时长由系统设置持久化，具体公式见 [缓存指标与健康评分](/logic/cache-and-health-score)。

## 调用对比与版本检查

```text
渠道使用日志 / 中转站用量同步 → 本地近期样本与时间桶
→ 账号关联限定候选 → 单条配对 / 时间桶对齐 → 悬停对照与明细查询
```

单条配对有相对位置回退，时间桶有最近开始时间回退；两侧并排数据用于辅助排查。页面查询不发起真实性能测试，规则见 [渠道与中转站调用对比](/logic/call-comparison)。

```text
构建参数 → 运行版本信息 → 系统设置显示
手动检查更新 → 后端查询 GitHub 最新稳定 Release → 缓存与版本比较 → 更新状态
```

版本检查沿用后台认证，成功结果缓存 5 分钟、失败缓存 1 分钟；没有 Release 与查询失败单独返回状态，检查不自动替换镜像。详见 [版本与更新](/reference/versions)。

## 本地资产与采购

本地账号登记 → 唯一名称匹配 / 手动远端关联 → 本地状态变化 → 自动采购账本。关联不创建远端账号或开启调度；删除本地条目仍保留采购事实。见 [本地号池与采购账本](/logic/local-account-lifecycle)。

## 鹈鹕测智

```text
全局方案 + 来源自动开关 / 单次参数 → 指定账号直连或分组网关生成
→ 完成状态及 HTML / SVG 校验 → 按账号 / 分组保存结果
→ 渠道关联汇总 / 号池 / 分组 / 独立作品库按需读取
```

自动运行同时受已保存时区、星期和时间段限制，以数据库租约防止同一来源重复领取；失败也保存结果。指定账号使用 Sub2API 导出的原账号凭据，不触发登录或续期；分组使用目标组的专用网关 Key。画廊预览在受限 iframe 中运行，公开监控仅提供可公开分组的成功作品，见 [鹈鹕测智与作品历史](/logic/pelican-testing)。

## 任务执行记录与 Token 维护

自动任务包装器 → 创建运行记录 → 收集脱敏日志 → 保存成功 / 失败、耗时和摘要 → 系统设置执行记录。服务重启会标记未结束记录为中断失败；业务日志保留期不自动清理这张表，见 [定时任务执行历史](/logic/task-execution-history)。

Token 刷新独立扫描开启监控的 Sub2API Token 模式凭据，使用已保存 Refresh Token 续期并记录结果，不与作品生成调用绑定，见 [同步与数据处理](/logic/synchronization)。

## 通知与验证码

采集事件 → 变化幅度 / 冷却 → 各通知渠道订阅筛选 → 合并 / 投递重试 → 结果日志。验证码另走绑定 Provider 求解及上游登录流程。测试发送不验证完整业务策略，见 [通知与验证码规则](/logic/notifications-and-captcha)。

## 公开视图

公开分组监控按需读取远端成功与最终失败记录，去掉已恢复的中途错误并返回安全摘要；模型目录使用分组网关 Key，报价结合当前组 / 渠道规则；官方服务状态读取官方状态页。

这些视图使用独立缓存，来源失败与旧视图须明确区分。查看 [公开页面的数据规则](/logic/public-monitor-and-pricing)。
