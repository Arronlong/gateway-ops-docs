# 项目概览

GatewayOps 为 NewAPI / Sub2API 生态提供统一的运营与监控界面，用于查看渠道余额和倍率、跟踪调用与延迟、管理 Sub2API 中转站、记录经营收支，并汇总 OAuth 账号池使用情况。

## 适用场景

- 需要集中查看多个 NewAPI 或 Sub2API 渠道的余额、状态和倍率变化。
- 运营 Sub2API 中转站，需要同步账号、分组和关联关系，并分析调用成本与风险。
- 需要记录收入、上游充值和账号采购等收支，并与调用统计进行对照。
- 需要通过通知及时发现低余额、倍率变化、登录失败或监控异常。

## 产品边界

GatewayOps 是运营管理层，不代替 NewAPI 或 Sub2API 提供模型服务。渠道监控支持 NewAPI 和 Sub2API；中转站管理使用 Sub2API 管理 API。中转站页面的真实请求测试会使用所选分组的额度，执行前应确认测试次数和账号费用。

GatewayOps 使用 PostgreSQL 保存业务数据。渠道凭据、通知密钥和中转站管理员 API Key 等敏感配置由 `APP_SECRET` 加密；丢失或更换主密钥会导致已有密文无法解密。

## 主要功能

| 功能区域 | 主要用途 |
| --- | --- |
| 运营总览 | 汇总渠道、成本、倍率与账号风险信息。 |
| 渠道管理 | 管理渠道凭据、余额监控、分组倍率和同步任务。 |
| 中转站管理 | 管理 Sub2API 账号、分组、模型、成本覆盖和调度策略。 |
| 成本管理 | 维护经营账本，并查看用户扣费、渠道余额和成本口径。 |
| 本地号池 | 展示同步来的 OAuth 账号、状态与用量统计。 |
| 通知与验证码 | 配置告警投递渠道和 Turnstile 验证码服务。 |
| 公开页面 | 分享分组调用监控和模型价格信息。 |

## 主要术语

- **渠道：** 被监控的 NewAPI 或 Sub2API 服务及其账号、余额和分组倍率。
- **中转站：** 通过 Sub2API 管理 API 连接的运营对象，包含远端账号、销售分组和用户数据。
- **销售倍率：** 中转站分组对用户侧采用的倍率。
- **成本倍率：** 账号调用上游服务所对应的成本倍率。它可能来自同步数据、渠道分组关联或手工覆盖。
- **用户扣费：** Sub2API 记录的用户侧实际计费金额，不等同于 GatewayOps 手工录入的现金收入。
- **账本净额：** 账本中已记录收入减已记录支出的结果，不直接代表利润。

## 第一次使用

部署后建议依次完成：创建管理员登录、添加渠道、测试并同步渠道、配置通知；如果要使用中转站功能，再添加 Sub2API 并同步快照，为每个销售分组配置并启用分组 API Key，最后检查成本与风险建议。

进入 [快速开始](/start/quick-start) 查看最短部署路径，或打开 [产品使用指南](/guide/dashboard) 按模块操作。
