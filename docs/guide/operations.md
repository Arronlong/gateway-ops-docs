# 成本管理

成本管理包含两类数据：手工维护的现金收支账本，以及自动汇总的渠道余额、中转站用户扣费和账号调用成本。页面按时间范围筛选区间账目和使用数据，但当前渠道余额是读取时的快照值。

## 维护账本

收入类别包括用户收入、其他收入和采购退款回款；支出类别包括账号采购、上游充值、退款、运营支出和其他支出。记录可关联渠道、中转站或本地账号，便于后续按对象查询。

创建账目时填写方向、类别、金额、日期和说明。上游充值如果关联渠道，会影响手工余额渠道的余额调整；编辑或删除此类记录也会触发相应调整。操作前检查关联对象和金额。

## 理解汇总卡片

- **总收入 / 支出：** 所选范围内已记录的账本金额，并汇入中转站用户扣费。
- **现金净额：** 所选范围的收入减支出；不是应收应付，也不直接等同利润。
- **账号采购成本：** 账本中关联中转站账号采购的金额。
- **上游充值支出：** 所选范围内记录的上游充值。
- **当前渠道余额：** 所有渠道当前余额快照合计，不是所选时间范围的期末余额。
- **实际消耗成本：** 以当前实现的账本支出与当前渠道余额计算，具体公式见 [成本与倍率](/logic/cost-accounting)。
- **中转站用户消耗：** Sub2API 使用记录中的用户侧计费金额。
- **实时倍率：** 成本侧金额与用户消耗金额的比值；它不是中转站销售分组倍率。

当中转站账号成本未知、读取失败或使用数据不完整时，应同时查看完整性状态和失败账号数，不能把部分汇总当作完整利润结果。

## 对账建议

将账本上游充值和中转站调用成本作为不同来源的对账指标。余额快照消耗、用户扣费和账号实际调用成本的时间窗口及覆盖范围可能不同；出现差异时先核对窗口、账号匹配和数据完整性，再检查倍率覆盖。
