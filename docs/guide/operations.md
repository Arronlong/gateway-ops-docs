# 成本管理

成本管理并列展示现金账本、当前渠道余额、全站用户扣费及账号调用成本。先确认时间范围与来源，再解读成本和差异。

## 维护账本

收入类别包括用户收入、其他收入、采购退款回款；支出包括账号采购、上游充值、退款、运营支出、其他支出。填写金额、日期和说明，按需关联渠道、中转站或本地账号。

查看来源再编辑：手工记录由账本维护，历史导入记录不会再次按手工充值调整余额，本地采购记录跟随号池修改。手工上游充值关联手工余额渠道时，创建、编辑、删除会相应调整余额。

页面自动汇入 Sub2API 全站用户扣费作为收入，不要再次把同一金额手工记成收入。具体副作用见 [成本与倍率](/logic/cost-accounting)。

## 汇总卡片

| 卡片 | 解读要点 |
| --- | --- |
| 总收入 / 总支出 | 区间账本加自动用户收入，需避免重复记账。 |
| 现金净额 | 收入减支出，不直接等同利润或已完成收款。 |
| 当前渠道余额 | 当前快照，不随区间变成历史期末余额。 |
| 实际消耗成本 | 采购加充值减当前余额，最低为 0。 |
| 实时倍率 | 上述成本除以正用户扣费；不是销售倍率。 |
| 账号调用成本 | 当前有效倍率可重算历史区间；未知 / 失败须同时看。 |
| 渠道成本差异 | 区间充值减映射账号调用成本，用于排查来源差异。 |

按站点成本不自动分摊全部渠道余额。公式、币种与未知成本处理见 [成本与倍率](/logic/cost-accounting)，余额推算另见 [渠道余额与调用记录](/logic/channel-consumption)。

## 对账顺序

1. 对齐时间窗口及服务时区。
2. 检查账本是否漏记、重复或关联错误。
3. 查看账号成本来源、当前覆盖及观察时间。
4. 查看渠道关联、匹配账号数、未知 / 失败数和完整性。
5. 分开比较现金充值、余额下降、账号调用成本与用户扣费。

修改当前倍率后，历史区间汇总可能变化；逐条消费趋势仍按历史用量字段计算，不保证与重算汇总完全一致。
