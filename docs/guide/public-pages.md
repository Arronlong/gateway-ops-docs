# 公开页面

GatewayOps 提供无需后台登录的公开分组监控、模型价格和服务状态页面。分享前应检查中转站名称、分组可见范围及公开 URL，确认页面不会暴露不应公开的信息。

## 分组调用监控

为中转站公开分组启用监控后，可分享 `/public/relay-monitor/<中转站 ID>`。页面展示近期调用结果、响应耗时、成功与失败统计和趋势。浏览器会使用缓存并在后台刷新；状态来自最近调用记录，只作趋势参考，不代表当前请求一定可用。

![公开分组调用监控示例](/images/public-relay-monitor.png)

## 模型价格

公开模型价格页面路径为 `/public/model-pricing/<中转站 ID>`。页面展示当前销售分组可用模型；Token 价格按每 1M tokens 展示，按次价格按单次请求展示，生图价格可按分辨率区分。

模型和分组归属依赖 Sub2API 分组 API Key。缺少分组 Key 时，模型列表、价格覆盖或快速测试可能不完整。价格来源可为系统默认、渠道覆盖或分组独立生图定价；读取时以当前有效规则为准。

![公开模型价格示例](/images/model-pricing.png)

## 公开服务状态

服务状态页聚合组件当前状态、历史状态和事件更新。历史可用性是已观测数据的摘要；数据未知、未上报或尚无历史记录时，不应解释为正常。
