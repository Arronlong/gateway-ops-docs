# 公开页面

公开分组监控、模型价格与官方服务状态无需后台登录。先检查站点名、公开分组及对外地址，再分享页面。页面标题图标、顶部品牌和浏览器标签复用系统设置中的产品名称与图标，读取失败时回退默认品牌；公开页面不提供品牌修改入口，见 [系统设置](/guide/system-settings)。

## 分组调用监控

为需要公开的分组开启监控，分享 `/public/relay-monitor/<中转站 ID>`。页面展示窗口成功 / 失败、近期调用、延迟桶和状态；默认滚动 24 小时，也可切换范围。

状态按最新连续调用结果判断：最新成功为可用，连续 1–2 次失败为波动，至少 3 次失败为不可用；无记录为空闲，读取不完整为未知。中途故障转移后最终成功的错误会按请求关联过滤。

![公开分组调用监控示例](/images/public-relay-monitor.png)

这不是主动探活。近期明细最多 60 条，窗口统计覆盖所选范围。历史调用按页持续读取；延迟字段未提供时，桶状态按成功率呈现并提示字段缺失。关注数据完整性与更新时间，详见 [公开页面的数据规则](/logic/public-monitor-and-pricing) 和 [延迟与稳定性](/logic/latency-and-stability)。

### 分组测智作品

开启公开监控的分组可展示最近的成功测智作品，最多 3 份，支持打开交互预览；公开页面不提供启动、配置或删除操作。后台作品库仍可查看失败结果，公开作品详情不返回题目或失败详情。全局测智“页面展示”关闭后，公开作品也不再显示。

公开作品由分组网关实际生成，不代表指定账号的测试结果。分享前检查内容是否适合公开；范围与沙箱规则见 [鹈鹕测智与作品历史](/logic/pelican-testing)。

## 模型价格

路径为 `/public/model-pricing/<中转站 ID>`。为相关销售组配置有效网关 API Key 后查看模型目录；缺少 Key 时，目录或快速测试可能失败。

Token 价格按每百万 Token 展示，按次价格按请求展示，图片价格可区分分辨率。查看价格来源和销售分组倍率；缺字段不表示免费，缓存更新失败可能继续显示旧价格。

![公开模型价格示例](/images/model-pricing.png)

来源补全、计价单位及缓存规则见 [公开页面的数据规则](/logic/public-monitor-and-pricing)。

## 官方服务状态

按 OpenAI、Claude、DeepSeek 顺序切换官方状态标签，查看当前组件分组、事件和计划维护，展示最近 60 天历史。历史使用 UTC 自然日；OpenAI / Claude 的展示可用率按正常天数计算，DeepSeek 分组 / 组件可用率使用官方返回值，缺失时不显示虚构的 0% 或 100%。这些都不是当前中转站请求成功率。

获取失败时查看未知状态与提示；官方状态正常不能证明本实例代理或出口正常。

DeepSeek 数据来自官方 `https://status.deepseek.com/`。主摘要失败显示未知，历史接口不完整会保留可用的当前状态并提示缺失；组件上线前的日期不当作正常。来源与口径见 [公开页面的数据规则](/logic/public-monitor-and-pricing)。
