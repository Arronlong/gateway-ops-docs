# 系统设置

系统设置管理版本检查、全局品牌、全局同步任务、监控统计时长与最近数量、鹈鹕测智方案、界面显示与 iframe 策略。渠道监控、账号成本及中转站自动策略仍在各业务对象里配置。

## 版本与更新

页面显示当前版本、提交号和构建时间；“检查更新”查询 GitHub 最新稳定 Release，并提供发布说明入口。检查不会替换镜像或重启应用。

正常检查结果缓存 5 分钟，失败缓存 1 分钟；短时间重复点击可能返回原结果。限流、超时或没有发布记录不代表已是最新版。本地构建未注入信息时，提交号和构建时间可能为 `unknown`。接口状态、版本来源与镜像升级见 [版本与更新](/reference/versions)，具体产品变化见 [产品更新记录](/reference/changelog)。

## 品牌与产品名称

在“品牌与产品名称”卡片编辑产品名称、上传图标，并通过右侧效果预览检查顶部品牌栏、页面图标和浏览器标签。点击卡片标题行的“保存品牌设置”，保存成功后才应用到当前应用；只修改名称、上传图片或恢复默认图标不会自动保存。

| 设置 | 规则 |
| --- | --- |
| 产品名称 | 最多 40 个字符，不能包含控制字符；去除首尾空白后为空时回退 `GatewayOps`。 |
| 上传图标 | 支持非空 PNG、JPEG、WebP 原图，最大 1 MiB；浏览器按比例缩放、居中转换为 128 × 128 PNG，不拉伸变形。 |
| 恢复首页默认图标 | 清空自定义图标草稿，保存后使用默认 Activity 图标，不重置产品名称。 |
| 生效范围 | 顶部品牌名称与图标、页面主标题图标、登录页、公开页面、浏览器标签图标及 Apple touch 图标；功能区仍保留业务图标。 |

浏览器标题统一为“页面名称 · 产品名称”，没有页面名称时只显示产品名称。公开页面通过只读品牌接口获取名称与图标，无需登录；读取失败或自定义图标加载失败时回退默认显示，不能把秘密写进品牌名称或图标。

品牌、测智、界面与监控等卡片共用系统设置保存请求，会一并提交当前系统设置草稿；其他未保存修改也可能随本次保存生效。独立同步任务配置不属于该请求。其他已经打开的浏览器页面若仍显示旧品牌，可刷新重新读取；这不是跨会话实时推送。品牌配置存于现有 PostgreSQL 设置，无需单独文件存储或重启，详细限制见 [配置项](/reference/configuration)。

## 全局同步任务

渠道完整同步、中转站倍率探测和快照同步分别设置开关与间隔。倍率默认间隔 10 秒、快照默认 3600 秒，但只有已配置且开启才自动运行。

渠道首次保存任务设置后，切换为页面完整同步模式，旧的余额 / 倍率启动 cron 被替代；即使保存为关闭也不会自动恢复旧任务。保存后动态更新，无需重启。

配置全局周期不会替每个渠道打开监控，也不会替每个站点打开自动调组或优先级；具体执行顺序、重叠跳过及失败规则见 [同步与数据处理](/logic/synchronization)。

### 渠道 Token 刷新

“渠道 Token 刷新”是独立的维护任务，默认关闭、间隔默认 30 分钟，允许大于等于 1 的整数分钟。它仅处理启用监控的 Sub2API 渠道中采用 Token 模式的凭据账号，要求保存可用的 Refresh Token；New API、密码登录模式和暂停监控的渠道不会在此任务中续期。修改后随同步配置保存生效，不需要重启。

刷新错误会记录到对应账号及任务执行历史；单个账号失败不阻止其他账号尝试。它不等于模型测智，也不会通过测智触发 Token 刷新，具体范围见 [同步与数据处理](/logic/synchronization)。

### 执行记录

同步任务行、测智方案及其他定时任务入口提供“执行记录”，可查看状态、耗时、摘要和日志。只记录功能上线后的自动调度及接入同一记录流程的启动执行，不补造旧历史；记录中的成功也不保证每项上游字段齐全。任务覆盖、状态和保留规则见 [定时任务执行历史](/logic/task-execution-history)。

## 页面显示

可控制运营目录、渠道管理页以及倍率变化、渠道信息、近期调用、分组、稳定性、消费模块。父级关闭保留子项设置，重新启用后沿用原值。

开关修改后需点击“界面与页面”标题行右侧的“保存界面与监控设置”才会持久化。监控指标时间窗口则在上方“监控指标”卡片中保存。保存成功后导航、页面内容及近期监控指标按新设置显示。隐藏影响界面，不删除历史、不停后台任务，也不是 API 权限。想暂停采集应修改同步任务或对象监控开关。默认值见 [配置项](/reference/configuration)。

## 监控指标

“监控指标”区统一设置渠道和中转站账号的近期样本范围：

| 设置 | 默认值与范围 | 用途 |
| --- | --- | --- |
| 统计时长 | 默认 1 小时，允许 1–24 的整数 | 下拉常用值为 1、2、4、6、8、12、18、24 小时；已保存的其他有效整数也保留为选项。 |
| 最近数量范围 | 默认 60 条，允许 1–200 的整数 | 控制最近调用、近期指标、综合评分及两侧调用对比读取的样本上限。 |

统计时长是近期指标的回看窗口，不是后台同步频率；缓存命中率、重试感知成功率、TPS 和综合评分还会在时间窗口内取最多所设数量的样本，条带与时间桶的范围另见 [延迟与稳定性](/logic/latency-and-stability)。

修改后点击该卡片标题行右侧的“保存监控设置”。它与“界面与页面”标题行的“保存界面与监控设置”调用同一个保存操作，都会保存当前界面显隐选项、统计时长与最近数量；修改控件后不会自动保存。TPS 环形指标及独立排序复用这两项参数，但不改变综合健康评分的四项权重。公式、样本和缺项规则见 [缓存指标与健康评分](/logic/cache-and-health-score)。

## 鹈鹕测智方案

在“鹈鹕测智方案”配置 1–8 项方案，每项包含启用开关、模型优先列表、题目与思考强度；统一设置频率、时区、运行星期 / 时段和作品保留数，点击“保存测智设置”生效。定时每轮仅执行已启用且配置模型的方案，各一次；禁用方案保留参数，并从手动候选中排除。旧方案未保存启用字段时按启用处理，所有方案都禁用时无法开始新测智。账号 / 分组仍各自启用自动开关，不再单独维护模型或频率。

默认显示作品页面、允许任务执行，初始方案启用但模型为空，来源自动开关关闭；默认每天 `08:00`–`22:00`、`Asia/Shanghai`、每 30 分钟检查频率，保留 30 份。关闭页面不暂停任务；关闭任务阻止新的手动及定时生成，但已开始的一轮会完成。时段只限制自动运行，不限制手动测试。

保留数允许 1–100，调低后立即删除旧结果；不要把它当成只控制页面显示条数。单次自定义参数不会保存回全局配置。请求执行前会先出现“生成中”记录，结束后原位更新为成功或失败；禁用方案不取消已开始的一轮。完整来源、执行及安全规则见 [鹈鹕测智与作品历史](/logic/pelican-testing)。

## iframe 策略

默认禁止嵌入。启用后选择允许全部或主机白名单；白名单条目填写主机模式，不能附带协议、端口或路径。来源校验依赖 Referer，缺失时可能拒绝嵌入。

允许嵌入不会跳过登录；反向代理响应头也可能影响实际浏览器行为。匹配规则和认证关系见 [访问与显示策略](/logic/security-and-access)。

后台认证、数据库、主密钥、全局通知策略和历史保留属于部署启动配置，不能只在当前页面修改。见 [部署配置](/deploy/configuration)。

## 预警总开关与采集频率

v1.0.5 的规则在 [预警中心](/guide/alerts) 管理；预警总开关及采集频率仅通过受认证保护的 `/api/alerts/settings` 接口保存，系统设置尚无独立表单，不要将界面显隐或现有同步开关当成预警总开关。默认值、范围及生效边界见 [预警判定与安全自动化](/logic/alerts-and-automation)。
