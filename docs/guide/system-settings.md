# 系统设置

“版本与更新”显示当前运行版本、提交号和构建时间，点击“检查更新”可查询 GitHub 最新稳定 Release。状态和升级步骤见 [版本与更新](/reference/versions)。

系统设置管理全局任务、界面显示和安全策略。渠道或账号自身的策略仍在对应业务页面设置；保存全局配置不会自动覆盖所有局部选项。

## 后台任务

渠道余额和倍率监控有全局执行周期，并可在渠道页面启用或暂停单个渠道的监控。中转站快照同步和倍率探测是两种独立任务；快照同步不执行倍率探测。配置变更后检查任务开关、执行间隔和最近结果。

## 页面显示

可控制运营管理目录、渠道管理页面及渠道卡片内容的显示。隐藏页面只影响界面入口或展示，不等同于删除对应业务数据；直接访问被关闭的渠道管理页面也不会正常展示业务内容。

## 安全策略

iframe 嵌入策略可整体关闭，也可限定来源白名单。只有受信任的嵌入站点才应加入白名单。公网认证和密钥配置属于部署安全事项，参见 [安全、升级与备份](/deploy/security-backup-upgrade)。
