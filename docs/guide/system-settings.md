# 系统设置

系统设置管理版本检查、全局同步任务、界面显示与 iframe 策略。渠道监控、账号成本及中转站自动策略仍在各业务对象里配置。

## 版本与更新

页面显示当前版本、提交号和构建时间；“检查更新”查询 GitHub 最新稳定 Release，并提供发布说明入口。检查不会替换镜像或重启应用。

正常检查结果缓存 5 分钟，失败缓存 1 分钟；短时间重复点击可能返回原结果。限流、超时或没有发布记录不代表已是最新版。本地构建未注入信息时，提交号和构建时间可能为 `unknown`。接口状态、版本来源与镜像升级见 [版本与更新](/reference/versions)，具体产品变化见 [产品更新记录](/reference/changelog)。

## 全局同步任务

渠道完整同步、中转站倍率探测和快照同步分别设置开关与间隔。倍率默认间隔 10 秒、快照默认 3600 秒，但只有已配置且开启才自动运行。

渠道首次保存任务设置后，切换为页面完整同步模式，旧的余额 / 倍率启动 cron 被替代；即使保存为关闭也不会自动恢复旧任务。保存后动态更新，无需重启。

配置全局周期不会替每个渠道打开监控，也不会替每个站点打开自动调组或优先级；具体执行顺序、重叠跳过及失败规则见 [同步与数据处理](/logic/synchronization)。

## 页面显示

可控制运营目录、渠道管理页以及倍率变化、渠道信息、近期调用、分组、稳定性、消费模块。父级关闭保留子项设置，重新启用后沿用原值。

隐藏影响界面，不删除历史、不停后台任务，也不是 API 权限。想暂停采集应修改同步任务或对象监控开关。默认值见 [配置项](/reference/configuration)。

## iframe 策略

默认禁止嵌入。启用后选择允许全部或主机白名单；白名单条目填写主机模式，不能附带协议、端口或路径。来源校验依赖 Referer，缺失时可能拒绝嵌入。

允许嵌入不会跳过登录；反向代理响应头也可能影响实际浏览器行为。匹配规则和认证关系见 [访问与显示策略](/logic/security-and-access)。

后台认证、数据库、主密钥、全局通知策略和历史保留属于部署启动配置，不能只在当前页面修改。见 [部署配置](/deploy/configuration)。
