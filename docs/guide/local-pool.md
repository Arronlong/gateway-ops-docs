# 本地号池

本地号池页面汇总已登记的本地 OAuth 账号，以及从中转站同步的远端 OAuth 账号状态和使用统计。页面以统计和管理本地账号资料为主，不负责替代 Sub2API 的实时调度器。

## 查看统计

页面按账号类型、平台、状态和关键字筛选。可查看账号数量、正常数量、用户扣费、请求次数、Token 数和状态分布。切换时间范围只影响对应区间用量；账号清单与当前状态属于当前快照。

Token 统计来自同步的用量字段。不同 Provider 记录输入、输出和缓存 Token 的方式可能不同，不能仅凭汇总 Token 数推断账单金额。

## 维护本地账号

可登记账号采购成本、预计额度、有效期和备注，并尝试关联远端中转站账号。自动关联后检查匹配对象；关联错误会使采购成本、用量或成本报表归属到错误账号。

正常、未调度和异常是页面展示状态，不代表账号在上游的全部健康诊断结果。同步失败或快照过期时，先刷新数据再处理账号。
