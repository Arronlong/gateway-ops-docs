# 本地号池

本地号池维护采购、预计额度、有效期和本地资产状态，并可关联中转站远端账号。页面汇总远端 OAuth 状态与用量，不代替实时调度器。

## 登记账号

填写名称、标识和平台，按需填写采购成本、采购时间、预计额度、有效期和备注。类型默认 OAuth，状态默认可部署；同平台标识不能重复，成本与预计额度不能为负。

本地状态包括待准备、可部署、已部署、停用与退役。状态字段是资产登记；远端是否可调度、是否异常需另看当前快照。

## 关联远端

手动选择中转站及已有账号，或执行自动关联。自动关联按本地标识 / 名称与远端名称精确匹配，忽略大小写及两侧空格；唯一候选才关联，多个候选保持歧义，不自动任选。

关联成功后核对站点及远端 ID。待准备 / 可部署会变成已部署；解除已部署关联后回到可部署，不会替远端开启或关闭调度。

## 采购联动与统计

采购成本大于 0 时自动生成采购支出；修改成本或采购日期应在号池完成，避免重复手工记账。成本改为 0 会移除对应自动采购记录，删除本地资产条目则保留已发生采购事实。

区间扣费、请求和 Token 来自远端用量；预计额度仍是登记值，不保证等于实时余额。统计空缺时先检查关联、快照时间及读取完整性。

完整状态变化和账本规则见 [本地号池与采购账本](/logic/local-account-lifecycle)。

## 号池测智作品

号池页面按所选中转站的远端 OAuth 账号展示作品，每个账号提供自动开关、“测一次”及参数下拉，通常展示最近 3 份，可进入作品库查看该来源完整历史。本地资产登记不代替远端账号凭据；还须满足 Sub2API 账号直连所需权限和模型支持。

全局模型方案、频率、时区及保留数在系统设置维护；单次参数不改变全局配置。执行会产生模型调用费用，来源与作品规则见 [鹈鹕测智与作品历史](/logic/pelican-testing)。
