# 运营总览

运营总览汇集成本统计、渠道统计、中转站风险和调整记录。页面顶部的时间范围会影响对应的区间统计；总余额和累计充值等指标并非都受该范围约束，详见 [指标口径](/logic/metrics)。

![GatewayOps 运营总览](/images/dashboard.png)

## 查看总览

- **成本统计：** 展示账本收支、渠道余额和中转站用量相关成本。账本净额不是利润。
- **渠道统计：** 展示当前余额、累计充值、渠道状态、区间渠道消耗、用户扣费或调用消耗，以及可选的倍率变更统计。
- **中转站统计：** 汇总中转站、远端账号、成本已采集数量和风险状态。
- **调整记录：** 查看近期的分组、调度和优先级调整；记录说明调整来源和目标。

桌面端顶部导航支持菜单换行并随内容调整高度，避免菜单两端被裁切。导航栏的“刷新视图”使用紧凑图标按钮，悬停可查看提示，点击会刷新当前页面查询数据；不会发起测智或重启应用。

## 选择时间范围

首页提供今天、最近 24 小时、最近 7 天、最近 30 天及自定义开始 / 结束时间。自定义默认浏览器当天 00:00–23:59，包含所选结束分钟；预设自然日仍按服务端时区计算。切换后关注成本卡片、用户扣费、倍率变动和风险展示的来源；累计充值、当前余额与当前风险快照不会被区间选择重算。时区、日分桶及直接 API 调用的边界见 [指标口径](/logic/metrics)。

## 判断数据是否可信

如果显示成本采集不完整或账号匹配数量不足，先打开中转站管理检查最近同步时间、账号成本来源和账号映射。不要把缺失数据当成零成本。具体边界见 [成本与倍率](/logic/cost-accounting)。


## 继续查看规则

账号风险、余额消耗和当前经营成本各有独立来源。先用 [业务规则总览](/logic/index) 定位；常见问题可直接查看 [自动调组](/logic/auto-group-adjustment)、[自动优先级](/logic/auto-priority) 与 [延迟与稳定性](/logic/latency-and-stability)。

调整记录说明已经成功写入的分组、调度或优先级变化；一次批量操作可能只有部分账号成功，看到失败时仍需检查成功账号的记录与远端最终状态。
