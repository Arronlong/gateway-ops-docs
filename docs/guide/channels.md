# 渠道管理

渠道是 GatewayOps 监控的 NewAPI 或 Sub2API 服务。页面支持添加渠道与多个账号、测试登录、手动同步、配置周期监控，并查看余额、倍率、调用记录和趋势。

## 添加和验证渠道

1. 新建渠道并填写站点类型、Base URL 和认证方式。
2. 选择账号密码、Cookie / User ID 或 Token 等站点支持的凭据模式。
3. 运行登录测试；启用了 Turnstile 的站点需先在验证码服务中配置可用 Provider。
4. 首次连接成功后运行完整同步，检查余额和分组倍率。
5. 配置低余额阈值、监控开关和自动同步周期。

不同站点的凭据字段并不相同。若认证失败，检查 Base URL、登录参数、Cookie / Token 有效期、站点代理和验证码配置；不要将凭据直接贴入公开问题或日志。

## 查看余额和倍率

渠道卡片展示当前采集到的余额、最近采集时间、历史余额趋势和分组倍率。手工维护余额的渠道不执行站点登录同步；编辑时应明确该渠道使用自动还是手动余额模式。

“倍率变动”来自采集到的分组倍率快照比较。暂停监控的渠道不会执行自动余额和倍率监控；需要时可以手动同步。

## 查看调用和延迟

渠道若能提供请求使用记录，可查看请求量、调用消耗、近期样本和延迟桶。首字时间、总耗时、成功率与输出速度可能因上游数据缺失而为空；不同渠道支持的原始字段并不完全相同。

P50 / P95 表示该统计桶内的中位数和高分位数，不是单次请求延迟。账户关联对比只能作为排查参考，不能视为同一请求的严格追踪链路。

## 渠道消耗与用户扣费

渠道页面的调用消耗来自渠道自身日志。首页用户扣费则来自中转站使用统计，并通过账号与渠道的关联关系匹配。两者来源和覆盖范围不同，不应直接当作同一个指标，见 [指标口径](/logic/metrics)。

删除渠道会影响关联配置和历史数据。执行删除前先确认该渠道没有仍需保留的余额历史、倍率快照或凭据。
