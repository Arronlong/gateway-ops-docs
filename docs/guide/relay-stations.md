# 中转站管理

中转站管理当前面向 Sub2API 管理 API，可同步远端账号、分组、渠道、用户和关联关系。账号成本、分组倍率、模型范围和调度策略共同影响风险判断与调组建议。

## 添加并同步

1. 添加 Sub2API 地址和管理员 API Key。
2. 测试连接并运行实时同步，确认账号与分组快照正常。
3. 在 Sub2API 管理后台为每个销售分组创建并启用分组 API Key。
4. 回到 GatewayOps 再次同步，确认分组能读取可用模型和价格。
5. 分别配置快照同步与倍率探测计划。

管理 API Key 和分组 API Key 用途不同。缺少分组 API Key 时，模型价格和分组快速测试可能不完整或失败。

## 账号成本来源

账号成本可以来自同步到的 API Key 成本倍率，也可以通过成本覆盖选择手工倍率、关联渠道分组或自动关联。每个账号应检查成本来源和观测时间；成本未知的账号不会被当作零成本。

渠道分组覆盖依赖正确的渠道关联和分组名称。覆盖失效时先检查关联渠道、上游分组名称及倍率同步时间。

## 风险建议与账号操作

账号列表可显示当前销售分组、成本、利润参考、风险、延迟与消费趋势。筛选或排序不会改变账号配置。应用调组建议、批量修改并发或优先级、停用调度等操作会改变远端运行状态，执行前应核对选中账号。

模型类型会收紧自动调组的候选范围。可降级提示要求账号和候选分组具有匹配的模型类型；它与一般调组建议的候选规则并不完全相同，见 [风险与自动调度](/logic/risk-and-scheduling)。

## 真实请求测试

账号连接测试和分组快速测试可能向上游发出真实请求，消耗对应管理员额度并写入使用记录、错误记录或监控数据。只对必要的账号运行测试，并限制次数。

## 公开监控

需要对外分享分组近期调用情况时，启用相应分组的公开监控。公开页面不要求后台登录，只展示允许公开的分组数据；不要将其视为实时探活保证。详情见 [公开页面](/guide/public-pages)。
