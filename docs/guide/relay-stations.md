# 中转站管理

中转站管理支持 Sub2API 与 New API，汇总远端账号、分组、渠道及用户。两类平台的字段和可执行操作有差异；接入 New API 前先阅读 [New API 中转站规则](/logic/newapi-relay)。先建立快照和有效成本，再启用会写远端的自动策略。

## 添加与同步

1. 新增站点时选择 Sub2API 或 NewAPI，填写基础地址及对应管理员凭据。New API 的鉴权模式和 HTTPS 要求见 [New API 中转站规则](/logic/newapi-relay)。
2. 测试连接并同步账号、分组、用户及可读取的调用数据。
3. 对 Sub2API，为需要查看模型、价格或快速测试的销售组配置有效的分组网关 API Key；New API 的分组模型从管理员可访问的渠道配置读取，真实分组测试则使用匹配的令牌。
4. Sub2API 可运行 API Key 倍率探测；New API 需要配置渠道关联或手工成本。
5. 绑定账号模型类型，检查当前分组和候选，再按需开启局部策略及全局定时任务。

管理员凭据用于管理接口，分组网关 Key 用于目录访问或真实调用，二者用途不同。快照同步与 Sub2API 倍率探测也不同；页面刷新只是重新查询，见 [同步与数据处理](/logic/synchronization)。

## New API 能力差异

New API 渠道会映射为统一界面的中转站账号，可管理调度、优先级及支持的分组操作。New API 不提供 Sub2API 的并发、池重试、用户并发 / RPM 管理，也不支持 API Key 成本探测；缺失的并发值不会以 0 代替。

分组倍率修改依赖 New API 全局设置权限，通常需要 root 管理员。真实分组测试需要管理员名下与目标分组匹配的令牌。具体操作边界、quota 换算、日志缓存和成本来源见 [New API 中转站规则](/logic/newapi-relay)。

## 账号列表怎么看

| 字段 | 使用建议 | 规则 |
| --- | --- | --- |
| 成本与利润率 | 同时核对来源、成本和当前最低有效销售倍率。 | [成本与倍率](/logic/cost-accounting) |
| 风险与可降级 | 先看具体当前组，再看模型条件及推荐。 | [自动调组](/logic/auto-group-adjustment) |
| 综合评分、缓存命中、尝试成功率与 TPS | 关注统计时长、最近数量、尝试数、置信度和缺项；最近数量默认 60，可设为 1–200。TPS 单独显示和排序，不加入综合评分。 | [缓存指标与健康评分](/logic/cache-and-health-score) |
| 容量与调度 | 容量是当前并发 / 上限，可调度是独立开关。 | [指标口径](/logic/metrics) |
| 优先级与最近使用时间 | 自动排序和召回会覆盖手动优先级。 | [自动优先级与召回](/logic/auto-priority) |
| 区间消费与趋势 | 对齐窗口，并留意历史记录成本和当前倍率汇总的区别。 | [指标口径](/logic/metrics) |

筛选、排序或切换卡片不修改账号。成本覆盖、模型绑定、分组修改与并发操作有不同生效方式，保存后查看结果及同步时间。

账号列表还展示近期缓存命中、重试感知成功率与四项综合评分，并支持按缓存命中率和成功率排序；窗口在系统设置统一配置。评分因素、有效尝试及低置信度规则见 [缓存指标与健康评分](/logic/cache-and-health-score)。

## 对照渠道调用

在账号“最近调用”中悬停记录，可以查看当前账号与已关联渠道的首字时间、总耗时和输出速度。反向对照按渠道合并关联账号，候选只包含当前关系对应的渠道凭据记录。

悬停“时间稳定性”可比较请求数、成功率及延迟 / 输出速度 P50 / P95；点击非空桶打开调用明细，后台默认最多 30 条。两侧样本或字段缺失时先检查同步和账号关联，不能把缺失值当成真实的 0。完整规则见 [渠道与中转站调用对比](/logic/call-comparison)。

## 鹈鹕测智

中转站详情的“鹈鹕测智”页签展示账号作品；账号级执行仅支持 Sub2API 的 OpenAI 协议 API Key / OAuth 账号，使用指定账号的模型目录及导出凭据直连上游，需要管理员账号导出权限。New API 映射账号不支持这条路径。

分组区域另有分组测智，Sub2API / New API 均通过目标分组专用网关 Key 生成，与指定账号直连不同。公开监控开启的分组可在公开页面展示最近成功作品，但不开放执行或删除。

方案启用、模型、题目、思考强度及自动频率在系统设置统一配置；只有已启用且配置模型的方案参与新执行，来源处仍需启停自己的自动开关。生成前先出现“生成中”记录，结束后原位更新，运行中不提供播放或删除入口。“测一次”可从下拉菜单选择本次参数，不会修改全局方案。作品可手动删除、完整历史可到作品库查看；费用、留存和权限边界见 [鹈鹕测智与作品历史](/logic/pelican-testing)。

## 配置自动策略

亏损自动调组与无利润自动调组分别开启；自动优先级、长时间未使用召回也各自配置。当前均默认关闭，召回默认 180 分钟。

自动调组要求账号已绑定模型类型，成本有效，并存在需要调整的组；没有安全候选的亏损账号可被关闭调度。没有自动恢复调度步骤。

自动优先级把 OAuth 设为 1、API Key 按延迟设为 2–10，召回按每轮快照推进一级。快照保存后执行已启用的两类策略，倍率同步成功后也会执行自动调组；不是点击保存就立即全量执行。配置详情见 [自动调组](/logic/auto-group-adjustment) 和 [自动优先级与召回](/logic/auto-priority)。

## 手动与批量操作

可以应用建议、编辑组、追加可降级组、修改并发 / 优先级 / 同账号重试、切换调度及批量克隆。查看选中账号及成功 / 失败明细；批量操作允许部分成功，不会自动回滚成功账号。

追加可降级组保留原有组，不能当作替换。克隆出的账号默认不可调度，检查新凭据、模型和分组后再启用。范围及副作用见 [账号操作与测试](/logic/account-operations)。

## 真实请求与分组管理

账号测试和分组测试可能消耗上游调用额度；分组测试支持串行 1–10 次，依赖有效分组网关 Key。倍率探测不是同一种性能测试。

分组名称、状态、倍率、平台、OAuth 要求及模型类型会影响候选；空模型类型列表在自动候选匹配中允许任意已绑定模型类型。公开监控开关决定是否进入相应公开视图。v1.0.8 的公开分组页新增缓存、含重试成功率和 TPS 环形指标，复用全局监控采样；首行最终请求成功率及历史范围继续独立，见 [公开页面](/guide/public-pages)。

## 用户管理

用户列表可查看余额、所选范围用量、并发与风险，风险来自注册审计及固定规则。完整性不足时先核对审计来源，再手动处理状态或限制。风险分不会自动封禁，详见 [用户风险识别](/logic/user-risk)。

用户删除调用远端软删除并跳过管理员，返回各项结果；操作后检查远端用户状态。用户消费与账号成本也不应混为同一指标。

## 账号与用户预警

v1.0.5 可在 [预警中心](/guide/alerts) 针对账号倍率、成本、稳定性及用户消耗、余额、多 IP 配置规则。属性筛选控制目标范围，远端自动化当前仅适配 Sub2API；New API 不支持的操作会拒绝执行。该功能不替代本站点的自动调组与优先级策略；恢复前的人工介入与多规则约束见 [预警判定与安全自动化](/logic/alerts-and-automation)。
