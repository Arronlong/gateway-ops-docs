# 常见问题

## `docker compose up` 提示环境文件不存在

当前 Compose 配置引用 `.outbound-proxy.env`。如果不使用该文件中的代理设置，请创建空文件，或按本机部署需求移除对应的 `env_file` 配置。检查 `.env` 是否存在，并确认 `GATEWAYOPS_DATABASE_PASSWORD`、`APP_SECRET` 已设置。

## 应用无法连接 Sub2API

确认 Base URL、管理员 API Key 和容器网络可达。当前 Compose 默认依赖 `sub2api-deploy_sub2api-network` 外部网络；网络不存在时创建它，或修改 Compose 网络声明。跨主机部署需使用应用容器可访问的真实地址。

## 公网打开后没有登录页面

检查 `AUTH_ENABLED` 是否为 `true`，并确认 `ADMIN_USERNAME` 和 `ADMIN_PASSWORD` 已配置。认证关闭时，后台页面不会要求登录；不要将这种模式直接暴露到公网。

## 渠道同步或登录测试失败

检查站点地址、认证模式、凭据、代理和最近错误日志。启用 Turnstile 的站点还需绑定已测试通过的 CAPTCHA Provider。确认服务器时间正常，Token 未过期，并核对上游 API 是否发生变化。

## 公开模型价格缺少模型或价格

在 Sub2API 后台为每个销售分组创建并启用分组 API Key，再回到 GatewayOps 执行实时同步。分组 API Key 与中转站管理员 API Key 不同。

## 成本显示不完整或倍率为空

查看完整性标记、失败账号数和未知成本账号数；检查账号成本来源、渠道分组覆盖、账号与渠道映射以及读取窗口。实时倍率要求用户扣费分母为正值；没有扣费时为空是预期行为。

## 首页和渠道页的消耗不一致

核对是否有手工余额渠道。当前首页会对手工余额渠道使用关联账号调用成本，而渠道页使用渠道余额消耗汇总；两者可能不一致。进一步查看 [指标口径](/logic/metrics)。

## 延迟或成功率没有数据

检查所选窗口内是否有调用样本、上游是否提供相应字段、请求结果是否已知以及数据是否已同步。空值代表缺少有效样本，不应当作 0 ms 或 0% 成功率。

## 通知没有送达

先测试通知渠道，再检查事件订阅、渠道/分组过滤、倍率变化阈值、低余额冷却和失败重试日志。测试消息成功不代表该事件已被订阅。

## 恢复后凭据无法解密

恢复数据库时必须使用与备份对应的 `APP_SECRET`。更换主密钥不会自动重新加密已有密文。
