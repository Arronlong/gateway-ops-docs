# 产品更新记录

本页依据主仓库 Git 标签、提交记录、发布说明和对应源码整理功能变化和升级影响。当前文档更新到 GatewayOps `v1.0.3` 标签提交 `15e7745`；每个版本按其标签与实现记录，不以源码默认版本代替实际构建版本。

源码和 Dockerfile 未注入构建参数时的默认版本仍为 `1.0.1`；由 `v1.0.3` 标签触发的正式构建使用标签注入 `1.0.3`。开发版或自行编译版请以实例实际显示的提交号和构建信息为准。

## 2026 年 10 月 22 日：v1.0.3

对应正式标签提交：`15e7745`。本次发布包含 `v1.0.2..v1.0.3` 范围内的 11 个提交。完整内容见 [GitHub Release](https://github.com/Arronlong/gateway-ops/releases/tag/v1.0.3)；以下按发布说明与标签源码整理。

### 缓存指标与账号健康评分

- 渠道与 Sub2API 账号新增近期缓存命中率、重试感知成功率环形指标，并支持按缓存命中率和成功率排序。
- 缓存命中率改为按 Token 汇总加权；辅助调用、探测及已确认的 cyber 尝试不计入重试感知成功率。
- 系统设置新增 1–24 小时近期统计窗口，默认 1 小时，渠道和中转站账号共用；窗口保存后同步影响列表指标、排序及评分。
- 综合评分改为成功率、稳定性、缓存命中、延迟四项各 25%；任一项未知即不显示总分，不对剩余项重新加权，少于 10 次有效尝试标为低置信度。
- 修正缓存公式提示的百分比结果，补充监控指标独立保存入口，并修复列表标题未按配置显示统计时长的问题。

计算口径和边界见 [缓存指标与健康评分](/logic/cache-and-health-score)，设置入口见 [系统设置](/guide/system-settings)。

### 鹈鹕测智与作品画廊

- 新增 Sub2API 账号级 HTML / SVG 模型测智，可指定模型、题目、思考强度、并行份数和北京时间 Cron。
- 每账号默认关闭，可手动运行；画廊保留最近 30 份结果，支持交互预览、暂停、倍速和下载原始 HTML。
- 计划任务使用数据库租约防止同账号并行领取；New API 不支持该功能。
- 作品预览在受限 iframe 中运行，禁止访问外部资源和网络接口。
- 启动时自动同步测智所需表结构；也可按 [手动迁移文件](https://github.com/Arronlong/gateway-ops/blob/v1.0.3/backend/migrations/0006_account_pelican.sql) 执行。该功能要求上游支持账号级 `pelican-test` 接口，并会产生实际模型调用费用。

配置、费用、执行限制与作品安全见 [鹈鹕测智与作品历史](/logic/pelican-testing)。

### 升级检查

1. 备份数据库与 `APP_SECRET`，检查运行中的站点地址和管理员权限。
2. 当前 Compose 模板可设置 `GATEWAYOPS_IMAGE_TAG=1.0.3` 拉取固定版本；升级流程见 [Docker Compose 部署](/deploy/docker-compose)。
3. 确认 v1.0.3 容器启动完成并检查健康状态；启动时会自动同步测智表结构。
4. 鹈鹕测智默认关闭；启用前确认上游 Sub2API 支持账号级接口并了解调用费用。监控指标统计口径和综合评分已更新，与旧版数值不宜直接横向比较。

## 2026 年 10 月 21 日：v1.0.2

对应正式标签提交：`0e392e2`。本次发布包含 v1.0.1 之后的 10 个提交。

### New API 中转站管理

- 新增 New API 站点类型，可使用管理员用户名 / 密码、访问令牌或 Cookie + 用户 ID 接入。
- 同步 New API 渠道、分组、用户和用量日志，并将渠道适配为统一管理界面的账号。
- 支持管理已映射的调度 / 优先级、分组倍率、用户状态等操作，并执行分组真实调用测试。
- New API 与 Sub2API 的字段和权限并不等价：不支持并发、池重试、用户并发 / RPM 限额和 API Key 倍率探测；分组倍率修改需要相应全局权限。
- New API 报表补充完整分页、共享快照和短时缓存，改善使用记录及用户管理长时间读取不全的问题。

操作方式见 [中转站管理](/guide/relay-stations)，凭据安全、指标换算和能力限制见 [New API 中转站规则](/logic/newapi-relay)。

### 监控与界面优化

- 修复公开分组监控历史调用分页可能提前截断的问题；上游页数估算偏小时继续读取后续页面，超过安全上限则报错。
- 时间桶有请求但没有延迟字段时，改按成功率显示状态并提示“已有调用、上游未提供延迟”；空桶仍与缺字段区分。
- 优化 New API 管理页面布局、指标、权限提示、表单状态与图表交互。
- 顶部工具栏和小屏菜单新增文档站入口。
- 将“保存界面设置”按钮移到“界面与页面”标题行右侧。

数据口径见 [公开页面的数据规则](/logic/public-monitor-and-pricing) 和 [延迟与稳定性](/logic/latency-and-stability)。

### 升级检查

1. 备份数据库与 `APP_SECRET`，检查运行中的站点地址和管理员权限。
2. 当前 Compose 模板可设置 `GATEWAYOPS_IMAGE_TAG=1.0.2` 拉取固定版本。
3. 确认 v1.0.2 容器启动完成并检查健康状态；数据库会自动迁移中转站类型字段，旧站点保持 `sub2api`。
4. 如需 New API 管理，新增 NewAPI 站点并重新执行连接测试和快照同步。

## 2026 年 10 月 13 日：v1.0.0 之后的代码变更

### 调用对比与指标

对应提交：`4d5a704`（`feat(监控): 完善渠道与中转站调用对比`）。

- 渠道与中转站账号的近期调用支持双向关联对照，展示首字时间、总耗时和输出速度。
- 对照按当前账号关联选择候选，再以时间、模型、Token 数和相对位置配对；适用于辅助排查，完整匹配边界见 [渠道与中转站调用对比](/logic/call-comparison)。
- 时间桶增加输出速度 P50 / P95，调用明细增加交互及字段展示。速度与百分位计算见 [延迟与稳定性](/logic/latency-and-stability)。
- 调整搜索更新、浮层布局和明细展示，改善列表和指标查看体验。

使用入口见 [渠道管理](/guide/channels) 与 [中转站管理](/guide/relay-stations)。

### 版本检查与镜像发布

对应提交：`e668765`（`feat(版本发布): 接入版本查询与自动镜像发布`）。

- 增加运行版本接口和系统设置中的“版本与更新”，可查看版本、提交号、构建时间，并手动查询 GitHub 最新稳定 Release。
- 正式标签触发后端检查、`linux/amd64` 与 `linux/arm64` 镜像构建及 GitHub Release 发布；最高稳定版本推进 `latest`，预发布和开发构建使用各自标签。
- 默认发布 GHCR，Docker Hub 保持可选。未配置完整 Docker Hub 凭据时跳过该目标；仅使用 GHCR 无需配置 Docker Hub。
- 当前 Compose 镜像默认指向 `ghcr.io/arronlong/gateway-ops`，可通过 `GATEWAYOPS_IMAGE_TAG` 选择 `latest` 或固定版本。

接口状态、缓存及标签规则见 [版本与更新](/reference/versions)，运行镜像的操作见 [Docker Compose 部署](/deploy/docker-compose)。

### 升级时检查

1. 核对目标版本的正式 Release 与镜像标签，备份数据库和 `APP_SECRET`。
2. 使用旧 Compose 文件时，确认 `app.image` 已指向目标 GHCR 地址；使用当前模板只需设置镜像标签。
3. 重新创建应用后，在系统设置确认版本、提交号和构建时间；点击“检查更新”本身不会替换容器。
4. 同步渠道和中转站，抽查账号关联、近期调用、速度百分位与明细；缺失上游字段不会因升级自动补齐。
