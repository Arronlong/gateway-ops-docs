# 产品更新记录

本页根据主仓库 `docs/releases/v1.0.0.md` 与后续提交记录整理功能变化和升级影响。当前文档对照源码默认版本 `1.0.1`、提交 `e668765`，正式 Release 和可拉取镜像以主仓库实际发布结果为准。

## 2026 年 10 月 13 日：v1.0.0 之后的代码变更

### 调用对比与指标

对应提交：`4d5a704`（`feat(监控): 完善渠道与中转站调用对比`）。

- 渠道与中转站账号的近期调用支持双向关联对照，展示首字时间、总耗时和输出速度。
- 对照按当前账号关联选择候选，再以时间、模型、Token 数和相对位置配对；适用于辅助排查，完整匹配边界见 [渠道与中转站调用对比](/logic/call-comparison)。
- 时间桶增加输出速度 P50 / P95，调用明细增加交互及字段展示。速度与百分位计算见 [延迟与稳定性](/logic/latency-and-stability)。
- 调整搜索更新、浮层布局和明细展示，改善列表和指标查看体验。

使用入口见 [渠道管理](/guide/channels) 与 [中转站管理](/guide/relay-stations)。

### 版本检查与镜像发布

对应提交：`e668765`（`feat(版本发布): 接入版本查询与自动镜像发布`）。

- 增加运行版本接口和系统设置中的“版本与更新”，可查看版本、提交号、构建时间，并手动查询 GitHub 最新稳定 Release。
- 正式标签触发后端检查、`linux/amd64` 与 `linux/arm64` 镜像构建及 GitHub Release 发布；最高稳定版本推进 `latest`，预发布和开发构建使用各自标签。
- 默认发布 GHCR，Docker Hub 保持可选。未配置完整 Docker Hub 凭据时跳过该目标；仅使用 GHCR 无需配置 Docker Hub。
- 当前 Compose 镜像默认指向 `ghcr.io/arronlong/gateway-ops`，可通过 `GATEWAYOPS_IMAGE_TAG` 选择 `latest` 或固定版本。

接口状态、缓存及标签规则见 [版本与更新](/reference/versions)，运行镜像的操作见 [Docker Compose 部署](/deploy/docker-compose)。

### 升级时检查

1. 核对目标版本的正式 Release 与镜像标签，备份数据库和 `APP_SECRET`。
2. 使用旧 Compose 文件时，确认 `app.image` 已指向目标 GHCR 地址；使用当前模板只需设置镜像标签。
3. 重新创建应用后，在系统设置确认版本、提交号和构建时间；点击“检查更新”本身不会替换容器。
4. 同步渠道和中转站，抽查账号关联、近期调用、速度百分位与明细；缺失上游字段不会因升级自动补齐。
