# 指标口径

本页按界面字段查口径。计算细节、默认值与处理边界分别链接到专门规则页。名称相似的指标可能来自完全不同的数据源。

## 时间范围

| 选择项 | 统计窗口 |
| --- | --- |
| 今天 | 服务端本地时区当天 00:00 至读取时刻。 |
| 24 小时 | 从读取时刻向前滚动 24 小时。 |
| 7 天 | 当天及之前 6 个自然日，从当地 00:00 起算。 |
| 30 天 | 当天及之前 29 个自然日，从当地 00:00 起算。 |
| 全部 | 部分页面提供，不设统计起点。 |

Compose 默认 `TZ=Asia/Shanghai`。当前余额、账号状态、分组归属和自动策略风险来自当前快照；近期请求最多 60 条；全历史充值不随区间缩小。官方服务状态历史则用 UTC 自然日。

## 首页与渠道字段

| 指标 | 来源与公式 | 需要一起看什么 |
| --- | --- | --- |
| 总余额 | 当前渠道已知余额合计，手工渠道使用已保存手工值。 | 缺失余额、旧采样、多账号部分失败。 |
| 累计充值 | 渠道关联的全历史上游充值账本金额。 | 不是所有余额增加记录，也不是区间值。 |
| 正常渠道 | 启用监控且无最近错误的渠道数量。 | 不代表实时探活成功。 |
| 异常渠道 | 存在最近错误的渠道数量。 | 暂停监控也可能保留错误。 |
| 最低余额 | 启用监控且有余额的渠道中最低值。 | 不覆盖没有监控或余额未知的渠道。 |
| 倍率变动 | 所选窗口内已记录的倍率变化次数。 | 无采样不代表没有改价。 |
| 渠道余额消耗 | 余额下降采样与修正规则推算。 | 充值、暂时归零、采样密度及保留期。 |
| 渠道调用消耗 | 渠道自身使用日志或明确映射的账号成本。 | 不能当作余额差额。 |
| 渠道用户扣费 | 按账号与渠道关联汇总的 Sub2API 用户扣费。 | 匹配账号数、失败数及完整性。 |

首页对手工渠道的消耗可以使用映射账号调用成本替代，而渠道页汇总余额消耗。对账时注明页面、余额模式、时间范围和来源。详见 [渠道余额与调用记录](/logic/channel-consumption)。

## 中转站总览的计数与倍率空间

| 指标 / 字段 | 计算口径 |
| --- | --- |
| 账号数、分组数 | 当前本地快照条数，不是区间新增。 |
| 关联数 `assignment_count` | 当前账号与组的关联数量，一个账号多个组会多次计数。 |
| 已映射 / 成本采集数 | 当前账号倍率非空的账号数；仍需结合成本来源与未知状态判断可信度。 |
| 匹配关联数 `matched_assignment_count` | 倍率非空账号的启用、平台一致当前组关联数，不是独立账号数量。 |
| 总 / 平均倍率空间 | 各个有有效 `margin` 的账号空间求和 / 简单平均，没有用实际消费加权。 |
| 负空间账号数 | 亏损风险与无安全候选账号数合计，不含仅无利润。 |
| 各风险状态数 | 按当前风险状态分别计数，非选定窗口历史风险次数。 |
| 近期价格变更 | 所选窗口内本地记录的模型数、规则数等定价快照变化，依赖同步观测。 |

总览 API 的 `profit_ratio_total / profit_ratio_average` 实际承载倍率差额汇总，并不是账号列表的利润率百分比。未知、未启用与未分配也不能据总账号数简单相减为“盈利账号”。

## 成本卡片

| 指标 | 当前口径 |
| --- | --- |
| 总收入 | 区间账本收入加中转站全站用户扣费；重复手工记同一收入会重复累计。 |
| 总支出 | 区间已记录账本支出。 |
| 现金净额 | 总收入减总支出，不等于会计利润。 |
| 实际消耗成本 | `max(0, 区间账号采购 + 区间上游充值 - 当前渠道余额)`。 |
| 实时倍率 | 实际消耗成本除以区间全站用户扣费；没有正分母时为空。 |
| 账号调用成本 | 已知当前成本倍率乘区间基准成本；未知时可暂用远端正成本并标记不完整。 |
| 渠道成本差异 | 区间渠道充值减映射账号调用成本。 |

现金、余额、账号成本与用户扣费不能无条件相加。公式、来源优先级、修改账本影响见 [成本与倍率](/logic/cost-accounting)。

## 中转站账号字段

| 字段 | 含义与边界 |
| --- | --- |
| 成本倍率 | 当前解析后的有效成本，需同时看来源和观察时间。 |
| 当前最低销售倍率 | 有效当前组中的最低倍率，用于利润空间参考。 |
| 利润空间 `margin` | 当前最低有效销售倍率减成本倍率。 |
| 利润率 | `(当前最低有效销售倍率 - 成本倍率) / 成本倍率 × 100%`；成本非正或缺失时显示占位。 |
| 容量 | Sub2API 当前并发占用 / 并发上限，是并发状态，不是剩余额度；New API 未提供该字段时不展示。 |
| 优先级 | 数字越小优先级越高；基础自动排序使用 1 或 2–10，召回从当前值逐级调整。 |
| 调度 | 独立可调度开关；优先级调整不自动打开它。 |
| 区间消费 | 所选窗口账号使用统计，与全站用户扣费覆盖范围不同。 |
| 消费趋势 | 按逐条远端用量划入桶的用户扣费及账号成本。 |
| 风险 | 当前成本与分组规则得到的状态，不是全部历史利润。 |
| 可降级分组 | 比当前最低销售倍率低、仍高于成本，并匹配模型条件的候选。 |

New API 用户余额与日志用量按上游 `quota_per_unit` 换算，不能直接将原始 quota 数值解释为货币。该平台缺少并发字段时不参与容量比较，成本来源及完整性见 [New API 中转站规则](/logic/newapi-relay)。

账号消费趋势的成本优先用每条记录的 `account_stats_cost`，否则用记录的账号倍率乘基准成本，缺历史倍率时按基准成本；区间汇总则可用当前有效覆盖倍率重算。两者不同，调整当前覆盖后趋势与汇总不一定完全一致。

风险与自动修改见 [风险与调度概览](/logic/risk-and-scheduling)，用户风险与账号调组风险是两个不同系统，见 [用户风险识别](/logic/user-risk)。

## 请求、评分与空值

首字时间、总耗时单位 ms；输出速度为 `输出 Token × 1000 / 总耗时`，单位 tokens/s。P50 / P95 使用有效样本百分位，不是最新一次请求值。桶输出速度先逐条计算，再求百分位；耗时 P95 代表偏慢的一侧，速度 P95 代表偏快的一侧。

近期缓存命中率和重试感知成功率按配置的 1–24 小时窗口统计，默认 1 小时。综合评分由成功率、稳定性、缓存命中、延迟四项各 25% 合成；任何组成项缺失时不重新分配权重，评分显示 `--`。详情见 [缓存指标与健康评分](/logic/cache-and-health-score)。此分不参与自动优先级；延迟时间桶仍按 [延迟与稳定性](/logic/latency-and-stability) 的独立口径展示。

渠道与中转站可在近期调用和时间桶悬停中并排对照；候选按账号关联筛选，近期调用配对仍有相对位置回退。后台桶明细默认最多 30 条，列表条数可能小于桶请求总数，详见 [渠道与中转站调用对比](/logic/call-comparison)。

`-`、空值、没有样本、读取失败、旧快照以及真实的数值 0 要分别理解。成功率还需区分中转站状态码口径与渠道已知结果口径；完整性与缓存边界见 [同步与数据处理](/logic/synchronization)。
