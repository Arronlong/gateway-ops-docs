# 指标口径

本页解释界面中容易混淆的统计项。不同指标可能来自余额快照、渠道调用日志、Sub2API 使用记录或手工账本；名称相似不代表口径相同。

## 时间范围

| 选择项 | 当前统计窗口 |
| --- | --- |
| 今天 | 服务端本地时区当天 00:00 至读取时刻。Compose 默认设置 `Asia/Shanghai`。 |
| 24 小时 | 从读取时刻向前滚动 24 小时。 |
| 7 天 | 当天及之前 6 个自然日，从本地时区 00:00 起算。 |
| 30 天 | 当天及之前 29 个自然日，从本地时区 00:00 起算。 |
| 全部 | 部分页面提供，起点不设时间限制。 |

账号使用记录可能有短时缓存。切换时间范围不代表所有数据源会以同一时刻完成刷新。

## 总览与渠道指标

| 指标 | 当前口径 | 重要边界 |
| --- | --- | --- |
| 总余额 | 当前渠道列表中有余额值的渠道余额求和。手工余额渠道使用手工值。 | 当前快照，不是所选时间范围的期末余额。缺失余额的渠道不计入数值。 |
| 累计充值 | 当前渠道关联的全部历史上游充值合计。 | 全历史指标，不随首页时间范围缩小。 |
| 渠道状态 | 总数为渠道条数；异常数为存在最近错误的渠道；正常数为已启用监控且没有最近错误的渠道。 | 这不是对上游的实时探活。暂停监控且无错误的渠道也不会计入正常数。 |
| 最低余额 | 启用监控且有余额值的渠道中，余额最低者。 | 不代表未监控渠道的最低余额。 |
| 倍率变动 | 所选窗口内记录的倍率变化次数。 | 依赖定期或手动采集到的倍率快照；未观测到变化不等于上游没有改价。 |
| 用户扣费 | Sub2API 账号在所选窗口内报告的用户侧实际扣费。 | 通过账号与渠道/中转站匹配汇总；显示匹配账号数和完整性状态。 |

### 渠道消耗不是单一数据源

自动余额渠道的消耗来自余额快照差额，并通过充值调整避免将充值误当成消耗。手工余额渠道无法依赖站点余额快照，首页汇总会使用关联账号调用成本作为替代口径。渠道管理页的汇总则读取渠道余额消耗数据。

因此，首页和渠道页的“渠道消耗”在手工余额渠道上可能不一致。对账时记录页面、渠道余额模式、时间窗口和数据来源，不要将两页数值直接视为同一个原始统计。

### 调用消耗与用户扣费

- **渠道调用消耗：** 来自渠道自身使用日志或按账号映射得到的调用成本。
- **中转站用户扣费：** 来自 Sub2API 的用户计费记录。
- **渠道余额消耗：** 根据渠道余额采样和充值调整计算。

三者的来源、映射覆盖率和时间窗口不同。关联不完整、远端查询失败或成本倍率未知时，汇总可能只包含部分账号；必须同时查看完整性提示，不能将未知成本解释成零。

## 请求与延迟指标

- **请求数：** 统计窗口内进入样本的调用记录数。成功率可能只使用结果已知的样本作为分母。
- **成功率：** 中转站延迟样本按状态码 `0` 或 `200–399` 记为成功；渠道样本按其已知结果字段判定，未知结果不纳入已知成功率分母。
- **首字时间：** 请求发起至收到首个响应内容的耗时，单位为毫秒。
- **总耗时：** 一次请求的总完成耗时，单位为毫秒。
- **P50 / P95：** 一个时间桶内对应指标的第 50 / 95 百分位。它们是分布统计，不是最近一次请求耗时；样本较少时高百分位波动较大。
- **输出速度：** 单次请求按 `输出 Token 数 × 1000 ÷ 总耗时毫秒` 计算，单位为 tokens/s。没有正输出 Token 数或有效总耗时时不计算。
- **输出速度 P50 / P95：** 先计算时间桶内每条有效请求的输出速度，再对这些速度求第 50 / 95 百分位；不是用总 Token 数除以总耗时。
- **时间桶：** 按当前查询窗口和选定粒度将请求分组。桶内没有可用样本的百分位字段可能为空。

渠道与中转站可能提供不同字段。渠道成功状态未知、延迟缺失或样本数量为零时，页面会显示空值或占位符，不应自行补成 0。

近期调用对照优先在 10 分钟范围内匹配模型名称或 Token 总数相符的记录；无法匹配时会按两组样本的相对位置配对。因此它是趋势比较参考，不代表同一个请求的可靠追踪关系。

## 时间稳定性评分

账号的时间稳定性综合分为 0–100，使用近期最多 60 条请求样本及时间桶统计：

1. 近期成功表现权重为 40%。
2. 近期延迟表现权重为 30%。
3. 时间桶稳定性权重为 30%，并按桶请求数加权。

延迟表现将首字时间和总耗时映射为 0–100 分，再按可用项取平均。首字时间 10 秒为警告阈值、30 秒为严重阈值；总耗时对应阈值为 60 秒和 180 秒。阈值之间按线性比例换算。桶稳定性使用成功率和 P95 延迟表现。若某个组成部分不可用，最终分数会在剩余可用部分之间重新分配权重。

此分数用于排序和比较，不是 SLA、模型质量评价或未来可用性保证。账号样本不足时可能没有分数。

## 缺失与延迟数据

- `—` 或空字段通常表示当前来源没有提供可用样本，不代表数值为零。
- 用户扣费和账号成本读取存在短时缓存，页面刷新后不一定立刻反映远端最新记录。
- 公开监控只反映近期实际调用记录，不能替代主动探活。
- 同一账号的跨渠道近期调用匹配是比较参考，不构成分布式追踪标识。
