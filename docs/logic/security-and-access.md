# 访问与显示策略

系统同时有后台认证、页面显示、iframe 嵌入和敏感配置加密。它们分别控制访问身份、界面呈现、嵌入来源及凭据存储，配置时应确认各自生效位置。

## 后台认证与公开接口

后台认证内置默认关闭；开启 `AUTH_ENABLED` 后需要管理员账号密码。会话默认有效 168 小时。登录 Token 签名密钥优先使用 `AUTH_TOKEN_SECRET`，未填时使用 `APP_SECRET`。

认证参数是启动配置，修改部署环境后需重新创建 / 重启应用。公开监控、模型价格和官方服务状态使用公开路由，不因为开启后台认证而全部变成需登录。完整部署设置见 [配置项](/reference/configuration)。

## 隐藏页面与卡片

页面显示设置保存在 PostgreSQL，保存后动态生效。运营目录、渠道页面及余额 / 倍率 / 延迟等卡片开关控制界面展示，不是接口权限或后台任务开关。

关闭父级页面会保留子项设置，再开启时恢复原子项值。隐藏某张卡片不会停止采集，不删除历史，也不会自动阻断公开接口。想停止采集应修改对应任务及渠道监控开关。

鹈鹕测智另有“页面展示”和“任务执行”开关：前者隐藏后台作品入口并关闭公开分组作品读取，后者阻止新手动 / 定时生成；已经开始的任务会继续完成。它们不是同一个开关，也不替代后台认证。公开只读作品来自开启公开监控的分组，详情不返回题目及失败内容；题目或生成作品仍不应携带秘密，见 [鹈鹕测智与作品历史](/logic/pelican-testing)。

## iframe 三种模式

| 设置 | 后端当前行为 |
| --- | --- |
| 禁用嵌入（默认） | 返回禁止嵌入的 CSP 与 `X-Frame-Options: DENY`。 |
| 启用、允许全部 `all` | 移除本模块的嵌入限制响应头。 |
| 启用、白名单 `allowlist` | 读取请求 Referer 的 HTTP / HTTPS 来源，按主机白名单匹配后生成对应来源的 CSP。 |

白名单默认空。Referer 缺失、格式无效、来源不匹配或模式不识别时，按拒绝嵌入处理。当前白名单匹配的是主机，成功生成的来源仍包含协议与端口，因此不能把条目理解成任意 URL 路径匹配。

主机条目支持精确主机、单层标签中的 `*`、占完整标签的 `**`；`*.example.com` 匹配一层子域，`**.example.com` 匹配至少一层子域，不自动匹配根域 `example.com`。需要根域时另加精确条目。条目不能包含协议、路径或端口；单独 `*` 会允许所有主机。

当前代码允许的部分带下划线主机不能生成标准 CSP 主机来源，匹配后可能不返回限制头；需要可靠限制时优先使用标准域名并检查实际响应头。

策略依赖浏览器传递的来源及 CSP 支持；反向代理若另设 CSP / X-Frame-Options，也会影响结果。启用嵌入不会跳过后台登录，白名单也不等于用户身份授权。

## 凭据加密与主密钥

渠道凭据、验证码密钥、通知配置和中转站管理员 API Key 使用应用主密钥加密保存。更换 `APP_SECRET` 不会自动重新加密已有密文；恢复数据库时需要配套的原密钥。

代理、可信代理地址和外部访问地址为网络配置，不等于凭据有效性。看到登录失败应结合认证模式、会话和上游错误排查，见 [渠道管理](/guide/channels)。

## 预警远端操作权限

预警管理及设置接口沿用后台认证，不作为公开状态接口暴露。规则可以产生真实远端启停动作，应先核对数字 ID、所属站点及能力；当前仅 Sub2API 适配，New API 不支持的操作拒绝执行。自动恢复还受事件所有权、人工介入和其他规则约束，见 [预警判定与安全自动化](/logic/alerts-and-automation)。

## 公开品牌信息

`GET /api/public/branding` 只读公开产品名称与图标，供登录页和公开页面使用；不需要后台登录，也不放开系统设置写入权限。品牌修改仍走受认证保护的系统设置接口，服务端独立验证名称与图片。不在名称、图标中嵌入秘密或内部资料；自定义品牌不会改变账号权限、站点数据公开范围或 iframe 策略，见 [系统设置](/guide/system-settings)。

## 渠道测智 Key 与自定义 Header

渠道 `pelican_api_key` 使用 `APP_SECRET` 加密，渠道配置接口只返回 `pelican_key_configured`，不会回显密钥；备份 / 恢复数据库时必须保留配套主密钥。该密钥用于关联账号测智或纯渠道直连，不等同于渠道管理凭据或分组网关 Key。直连接口使用后台认证，不向公开分组提供执行、详情或删除接口；返回结果时不暴露保存的 Key。

自定义 `login_headers` 是可编辑渠道配置，会随受认证保护的渠道读取接口返回，配置值不应视为加密秘密。避免在静态 Header 中放长期有效的 API Key；优先使用专用加密凭据字段或动态会话占位符。Headers 可覆盖默认认证头，因此配置错误也可能改变登录、校验、续期和后续上游请求。见 [渠道管理](/guide/channels) 与 [配置项](/reference/configuration)。
