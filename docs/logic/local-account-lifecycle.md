# 本地号池与采购账本

本地号池保存采购、预计额度、有效期与远端关联。它是运营资产登记，不代替 Sub2API 实时调度；本地状态和远端可调度状态是不同字段。

## 登记约束与默认值

名称、标识、平台必填；采购成本和预计额度不能为负。平台、类型、状态和标识会去除两侧空格并归一大小写；名称只去除两侧空格。

账号类型默认 `oauth`，状态默认 `ready`，未填采购时间时使用当前时间。同平台下的本地标识不能重复。预计额度为人工登记值，不会因为名称关联就自动变成上游实时剩余额度。

| 状态 | 含义 |
| --- | --- |
| `pending` | 待准备。 |
| `ready` | 可部署。 |
| `deployed` | 已部署登记。 |
| `disabled` | 人工停用登记。 |
| `retired` | 退役登记。 |

这些是当前允许保存的本地状态，不是对所有上游异常原因的自动分类。

## 手动关联与状态变化

中转站 ID 与远端账号 ID 要同时填写或同时清空；关联对象必须存在于当前本地中转站快照。建立关联时，`pending` / `ready` 自动变成 `deployed`；解除关联时，原 `deployed` 变为 `ready`。其他人工状态不会一律重置。

关联只表示本地资产与远端对象的对应，不会创建远端账号、替它绑定销售组或开启调度。

## 自动关联如何匹配

只处理尚未完整关联的本地账号，使用本地标识或名称，与远端账号的名称做去空格、忽略大小写的精确匹配。按站点与远端账号 ID 去重后：

- 只有一个候选：建立关联。
- 没有候选：记为未匹配。
- 多个候选：记为歧义，不自动选一个。

这不是按 API Key、Base URL 或邮箱所有权验证，也没有通过调用确认账号真实身份。多个中转站使用同名账号时，应手动检查和选择。自动匹配的结果须结合远端名称与站点核对。

## 采购账本联动

采购成本大于 0 时，自动创建或更新来源为 `local_account` 的账号采购支出，金额和采购日期跟随本地账号；当前自动记录货币为 CNY。成本改为 0 时，删除该自动采购记录。

编辑采购成本应在本地号池完成，避免另外手工重复记一笔同一采购。删除本地账号时，已发生的采购账本事实保留并解除本地引用，不因为资产条目删除就冲回全部采购支出。

## 统计边界

区间用户扣费、请求和 Token 来自关联远端用量，当前状态来自最近快照。切换时间范围改变用量窗口，不改变采购日期或当前状态。关联失败、对象被删除或快照过期时，缺失用量不能被当成零成本。

页面上的正常 / 未调度 / 异常状态展示，还需要结合远端状态、可调度字段及错误信息；本地 `ready` 不代表上游凭据已经通过测试。操作见 [本地号池](/guide/local-pool)。
