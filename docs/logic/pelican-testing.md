# 鹈鹕测智与作品历史

鹈鹕测智是中转站账号级的模型生成测试。它将题目发给指定 Sub2API 账号，再把模型返回的 HTML / SVG 作品和执行结果存入该账号的历史画廊；它不是普通连通性测试、倍率探测或公开分组监控。

## 适用范围与配置

当前只支持 Sub2API 中转站。New API 站点不支持此接口，不应在 New API 账号上启用。每个远端账号独立保存配置，默认关闭。

配置项包括：

| 配置 | 规则 |
| --- | --- |
| 模型 | 必填，最多 256 字节；应选择该账号实际支持的模型。 |
| 题目 | 最长 32000 字节；空值恢复默认鹈鹕骑自行车 SVG 动画题目。发送时会附加只输出独立 HTML 的约束。 |
| 思考强度 | `none`、`minimal`、`low`、`medium`、`high`、`xhigh`、`max` 或 `ultra`；默认 `medium`。 |
| 并行份数 | 每轮同时生成 1–8 份，默认 1。每份都是单独模型调用，可能产生相应上游费用。 |
| 计划频率 | 五段 Cron，按北京时间 Asia/Shanghai 解释；默认每 30 分钟。未启用时不自动运行。 |

在账号行配置和启停鹈鹕测智；“测一次”可立即运行一轮。中转站详情的“鹈鹕测智”页签按账号查看配置及历史作品。作品还没有生成，或账号尚未同步到本地时，不会显示相应历史。

## 执行与结果

手动和计划任务都将请求发送到目标账号专用的 `pelican-test` 上游接口，不会改用其他账号或普通分组测试接口。单轮请求最长 10 分钟，上游完整响应最多 4 MiB，解析后保存的作品最多 2 MiB。没有完整 HTML / SVG，或没有上游成功完成事件时，结果记为失败而不是生成占位作品。

后台约每 30 秒扫描到期计划；每账号通过数据库租约防止多进程重复领取。手动或计划任务执行时租约最长 15 分钟。计划任务在结果保存后才推进下一次时间；如果期间编辑了频率，不覆盖新设置。账号暂时从同步快照消失时保留配置和历史，但不执行孤立配置。每账号保留最近 30 份结果，成功和失败都会记录。

计划任务异常时，运行租约过期后可重新领取；这不保证异常重启时模型调用恰好执行一次。检查结果时间、状态和错误详情，不要仅凭启用开关判断模型调用已成功。

## 作品播放与安全

画廊先读取结果列表的元数据，再按需读取作品内容。打开作品后可以暂停 / 恢复动画、重播、选择 0.25×–4× 播放速度、适配窗口、按 100% 查看以及下载原始 HTML。作品预览采用隔离 iframe；沙箱只开放脚本执行，不授予同源访问，内容安全策略禁止网络连接及外部资源。作品保留模型生成内容，不由 GatewayOps 重新绘制。

测智会向上游发起真实模型调用，并保存提示词、模型、执行状态和生成作品。启用自动频率或增加并行份数前，确认上游额度、费用和内容合规性。停止计划任务不会删除历史；删除站点会按站点数据清理规则处理关联配置与作品。
