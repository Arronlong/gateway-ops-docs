# 鹈鹕测智与作品历史

鹈鹕测智将题目发送给模型，保存返回的 HTML / SVG 作品和执行结果，用于比较模型生成效果；它不是连通性测试、倍率探测或健康评分。以下规则对应 GatewayOps `v1.0.4`，与 v1.0.3 的账号独立参数和专用接口不同。

## 来源与使用入口

| 来源 | 入口与执行对象 |
| --- | --- |
| 渠道关联账号 | 渠道卡片展示最近作品，作品库按渠道汇总；真正执行的是已关联的中转站账号，不是重新使用渠道登录接口生成。 |
| 本地号池 | 号池页面展示所选中转站的远端 OAuth 账号作品，可手动运行或启停该账号的自动测智；本地资产登记本身不是执行凭据。 |
| 中转站账号 | 中转站详情的“鹈鹕测智”页签，按指定 Sub2API 账号执行与查看历史。 |
| 中转站分组 | 分组区域运行测智；通过目标分组专用调用 Key 使用网关，不保证由某个固定账号执行。Sub2API 和 New API 分组均可走此路径。 |

独立作品库路径为 `/pelican`，按渠道、号池账号和中转站分组分组，最新结果在前。支持名称 / 模型搜索、中转站及成功 / 失败筛选，组内可按模型和思考强度筛选；入口卡片通常只显示最近 3 份，完整历史到作品库查看。渠道无有效账号关联时，应先同步并建立关联，不能把其他渠道的作品当成本渠道结果。

## 全局方案与保存

在“系统设置 → 鹈鹕测智方案”统一配置，点击“保存测智设置”生效。账号 / 分组只保留各自的自动测智开关和执行状态，自动开关默认关闭；保存全局参数不会自动开启来源。

| 配置 | 规则 |
| --- | --- |
| 页面展示 | 默认开启；控制作品页面、导航和相关作品区，不等于暂停任务。公开分组作品也受此开关控制。 |
| 任务执行 | 默认开启；控制新的定时及手动测智，关闭不取消已开始的一轮。仍需配置模型并开启来源自动开关才会定时生成。 |
| 测智方案 | 1–8 项，每项包含模型优先列表、题目和思考强度。定时每轮将已配置方案各运行一次，方案之间并行；不再以旧版“并行份数”决定重复生成数量。 |
| 模型优先列表 | 每项最多 256 字节，可换行或用中英文逗号 / 分号分隔，按顺序匹配上游模型目录中的可用文本模型；支持 `*` 匹配。多方案时每项都需配置模型。 |
| 题目 | 必填，最多 32000 字节；可点击“恢复默认题目”填回鹈鹕骑自行车动画题目。发送时附加只输出独立 HTML、无外部依赖的要求。 |
| 思考强度 | `none`、`minimal`、`low`、`medium`、`high`、`xhigh`、`max` 或 `ultra`；默认 `medium`。 |
| 自动频率 | 五段 Cron（分 时 日 月 周），默认每 30 分钟；还须同时满足运行星期和时间段。 |
| 时区 / 时段 / 星期 | 默认 `Asia/Shanghai`、每天 `08:00`–`22:00`；使用已保存时区，不是浏览器或服务器自动推断的时区。 |
| 保留数量 | 每个中转站账号或分组保留 1–100 份结果，默认 30，包含成功与失败。降低上限会立即删除超出部分；调高不能恢复已删作品。 |

模型优先列表用于生成前选型，不表示请求失败后自动改用下一个模型。缺少模型或目录中无匹配项时不发送生成请求，而是提示配置 / 支持范围问题。列表为空的默认方案可保留，但不能用于执行。

自动时段包含开始时刻、不包含结束时刻；起止相同表示全天。跨午夜时，凌晨部分归属于开始日，例如周五 `22:00`–次日 `02:00`，周六凌晨仍按周五的选择判断。修改时区、星期、时段或频率会重算下次时间，时段外任务不会集中补跑。已开始的一轮继续使用启动时参数。

## 单次自定义测智

“测一次”使用系统模型选项中的首个模型及其题目、思考强度。点击旁边的下拉按钮，可选择本次模型并修改题目与思考强度，再点击“手动测一次”。这只影响本轮，不修改全局方案或自动频率。

手动模型必须来自系统设置中已配置的模型列表；不能在请求中任意指定其他模型。单次请求只接受一个方案，题目非空且不超过 32000 字节，思考强度必须有效。手动测试不受自动运行时段及星期限制，也不要求来源的自动开关已开启，但仍受全局“任务执行”开关限制。直接调用 API 且不传单次方案时，会使用所有已配置全局方案，和页面按钮显式选择单个方案不同。

## 凭据、调用路径与能力边界

**指定账号路径：** 仅支持 Sub2API 的 OpenAI 协议 API Key / OAuth 账号。系统先读取该账号模型目录，再通过管理员账号导出接口读取唯一指定账号的凭据、模型映射与代理；管理员需要账号导出权限。随后使用该账号凭据直连其上游，API Key 按账号能力选择 Responses 或 Chat Completions，OAuth 使用已有访问令牌。New API 的映射账号不支持这条路径。

不再要求上游提供旧版 `pelican-test` 专用接口，也不会退回普通账号连通性测试生成作品。凭据缺失或被脱敏、代理不完整、模型不支持时明确失败，不偷偷切换其他账号；测智不负责登录、Token 续期或账号维护。Sub2API 渠道维护任务与此独立，见 [同步与数据处理](/logic/synchronization)。

**分组路径：** 先同步目标分组，读取其专用网关 Key 和可用模型，再通过网关 Chat Completions 生成。Sub2API 要求绑定到当前组且启用的管理员调用 Key；没有专用 Key 时不借用其他组。New API 使用管理员名下匹配目标组的令牌。分组作品反映网关调度结果，不证明某个账号一定被调用。

渠道作品可展示关联上游 Key 的分组名称与倍率；读取不到时保留未知，不把缺失倍率当零。身份、分组与费用应结合实际执行来源核对。

## 执行与留存

后台约每 30 秒检查到期计划，账号 / 分组使用数据库租约防止同一来源重复并行领取，租约最长 15 分钟。生成执行最长 10 分钟；单条 JSON / 流事件上限 16 MiB，累计文本输出上限 4 MiB，提取保存的作品上限 2 MiB。流未完整结束、上游报错或没有完整 HTML / SVG 时记录失败，不创建占位作品。

结果记录包含模型、思考强度、题目、手动 / 定时触发、耗时及成功或失败详情。作品列表先读取元数据，完整内容按需读取；计划结果保存后才推进下一次时间。异常重启后租约到期可重新领取，但不保证模型调用恰好执行一次。定时调度检查是否成功和每份作品是否成功应分开看，见 [定时任务执行历史](/logic/task-execution-history)。

登录后台后可手动删除单份作品，删除需确认，不能撤销；它删除当前账号或分组对应的底层结果，多处引用的同一作品会一起消失，不只是移除缩略图。删除不会关闭自动计划，后续仍可能生成新作品。降低全局保留数也会立即清理较早结果。

## 作品播放与安全

画廊先读取结果列表的元数据，再按需读取作品内容。打开作品后可以暂停 / 恢复动画、重播、选择 0.25×–4× 播放速度、适配窗口、按 100% 查看以及下载原始 HTML。作品预览采用隔离 iframe；沙箱只开放脚本执行，不授予同源访问，内容安全策略禁止网络连接及外部资源。作品保留模型生成内容，不由 GatewayOps 重新绘制。

公开分组监控只展示已开启公开监控分组的最近成功作品，最多 3 份；不提供测智执行、配置或删除操作，公开作品详情不返回题目和失败详情。页面展示关闭后公开作品入口也关闭，但这仍不是后台接口鉴权或任务暂停手段。

测智发起真实模型调用并保存作品。增加方案、来源数量或运行频率前，确认上游额度、费用和内容合规性；题目与作品不要包含秘密或不宜公开的信息。关闭自动开关不删除历史；删除站点会清理关联测智数据。
