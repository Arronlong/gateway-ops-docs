# 同步与数据处理

页面刷新、渠道完整同步、中转站快照同步和倍率探测分别做不同工作。查看“最近成功时间”和错误提示，可以区分新数据、旧快照和查询缓存。

## 同步类型

| 操作 | 读取与更新 | 是否执行账号自动策略 |
| --- | --- | --- |
| 页面刷新 | 重新查询 API，可能命中缓存。 | 不因刷新直接执行。 |
| 渠道余额采集 | 当前余额、余额快照及低余额检查。 | 否。 |
| 渠道倍率采集 | 分组倍率、变化记录及通知。 | 否。 |
| 渠道完整同步 | 依次尝试余额、倍率、支持的调用记录。 | 否。 |
| 中转站快照同步 | Sub2API 或 New API 的账号 / 渠道、组、关联及可读取的用量 / 延迟。 | 成功保存后执行已启用的调组与优先级；具体字段取决于平台能力。 |
| 中转站倍率同步 | 批量上游计费探测、成本观察及关联协调。 | 成功后执行已开启的自动调组，不执行优先级。 |
| 单账号倍率探测 | 指定 API Key 的计费探测及成本观察。 | 不直接执行调组或优先级。 |
| 账号 / 分组真实请求测试 | 发送测试请求，结果及用量由上游记录。 | 不是后台自动策略触发器。 |

中转站快照不会代替倍率探测。遥测读取失败可以保留上次延迟和成本观察，并继续保存其他快照；因此同步完成也不保证每项统计都是本轮新采集。

## 渠道任务有两种配置模式

**尚未保存页面同步配置时**，运行后端启动配置中的余额和倍率独立任务，内置默认分别为每 15 分钟的第 37 秒和每 30 分钟的第 13 秒。这些 cron 为含秒的 6 字段表达式。

**保存页面同步配置后**，渠道使用页面定义的完整同步任务，替代上述两个独立任务。页面默认间隔为 30 分钟、默认开关关闭；保存为关闭后，旧的独立任务不会自动回来。

所以“页面看到自动同步关闭”与“从未保存过页面配置”不能合并判断。排查时先确认是否已经保存配置，再确认启用状态和间隔。

## 中转站定时任务

倍率探测与快照同步分别有配置和开关。页面默认值分别为 10 秒、3600 秒，但未配置或未开启时不会按这些值自动运行。当前保存范围及环境默认值见 [配置项](/reference/configuration)。

保存同步设置会持久化到 PostgreSQL，并更新运行中的任务，不需要重启容器；它不会批量打开每个渠道的监控开关或每个中转站的策略开关。

同类任务重叠时跳过重叠轮次；中转站倍率与快照任务使用共享锁串行执行。配置很短的间隔不保证每轮立即完成。自动渠道完整同步有约 20 分钟执行上下文，中转站定时任务约 10 分钟；远端网络和排队可能决定实际完成时间。

自动扫描仅选择启用监控的渠道；手动“同步全部”可包括暂停监控的渠道。单个渠道失败不终止全部其他渠道。渠道完整同步即使余额失败，也仍尝试倍率及使用记录。

## 快照与远端写入顺序

```text
读取远端快照 → 保存本地 → 协调渠道关联 → 自动调组 → 自动优先级
```

读关键账号 / 分组 / 渠道列表失败会返回同步错误。保存后策略部分失败时，已经成功的远端修改保留，并记录失败情况；不是全站回滚。更改任务或重试前先核对调整记录和远端最终状态。倍率同步另走“更新成本 → 协调关联 → 自动调组”的路径，没有自动优先级阶段。

账号模型绑定、成本覆盖等本地配置与远端快照来源不同。更新本地规则后，要通过正确同步入口触发策略，不能把前端重新渲染当作执行成功。

## 查询缓存与数据新鲜度

| 数据 | 当前短时缓存 | 解读方式 |
| --- | --- | --- |
| 账号区间用量（含 New API 报表） | 约 1 分钟 | 按站点、窗口及账号集合区分；New API 成功与失败日志分页读取后共享报表快照。 |
| 公开分组监控 | 约 15 秒 | 仍是近期真实调用，不是实时探活。 |
| 公开模型价格 | 约 10 分钟 | 更新失败可能返回旧视图，必须查看更新时间。 |
| 官方服务状态聚合 | 约 30 秒 | 查看官方更新时间和读取错误。 |

这些是服务端缓存；页面还可能有自身的查询缓存和刷新节奏。切换时间窗口不等于立刻完成所有上游采集。

## 保留与清理

内置清理 cron 为每天 `03:17:00`。默认保留监控日志 30 天、余额快照及对应变化 90 天、通知日志 90 天；倍率变化日志不属于此定期清理。

对应保留天数为 `0` 表示不清理该项；清理 cron 为空则不启动清理任务。清理删除严格早于截止时间的记录，历史图表能展示的范围会随保留期缩短。

每日余额基线还有午夜采集与启动补采，见 [渠道余额与调用记录](/logic/channel-consumption)。数据留存配置不代替数据库备份。
