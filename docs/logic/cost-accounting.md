# 成本与倍率

成本管理同时展示现金账本、渠道余额快照、中转站用户扣费和账号调用成本。它们是相互校验的数据源，不应无条件相加。

## 现金账本

区间现金净额的基础口径是：

```text
现金净额 = 所选范围内账本收入 - 所选范围内账本支出
```

成本管理会自动汇入 Sub2API 用户实际扣费。因而页面总收入不一定只由手工录入的账本行组成。账号采购、上游充值、退款、运营支出等按各自账本类别汇总。

账本净额只代表已记录的现金收支差额，不含所有应收、应付、未登记采购或未结算余额，因此不能直接作为会计利润。

## 实际消耗成本

当前总览中的实际消耗成本按以下口径计算：

```text
实际消耗成本 = max(0, 区间账号采购支出 + 区间上游充值支出 - 当前渠道余额)
```

这里的渠道余额是读取时的全部当前余额快照，不是所选时间范围开始或结束时的历史余额。若统计范围很短，该公式也会使用当前余额；解释结果时必须保留这一时间口径。

## 实时倍率

```text
实时倍率 = 实际消耗成本 ÷ 所选范围内中转站用户扣费
```

没有正的用户扣费时不返回倍率。此处汇率按 1:1 处理，不做货币换算。这个指标表示当前口径下的成本金额与用户消耗之比，不是模型定价使用的销售倍率，也不是通常意义上直接展示的利润率。

由于分子使用账本支出和当前余额、分母使用 Sub2API 计费数据，该比值适合做运营趋势参考。解读时应同时确认完整性状态、未知成本账号数和统计窗口。

## 中转站调用成本

中转站调用成本由 Sub2API 使用记录及 GatewayOps 解析到的账号成本倍率计算。成本已知的账号计入成本汇总；读取失败或成本倍率未知的账号会进入失败/未知计数。部分成功时金额可能是部分汇总，不能假设缺失账号成本为零。

账号成本可能来自同步成本、手工倍率覆盖、关联渠道分组倍率或自动关联。优先核对账号成本来源和最近观测时间，再分析汇总变化。

## 渠道消耗和对账差异

渠道余额消耗根据余额采样与充值调整得到；中转站调用成本来自账号用量统计。页面还会展示渠道支出和中转站调用成本之间的差异：

```text
渠道成本差异 = 所选范围内渠道上游充值 - 所选范围内中转站账号调用成本
```

余额消耗、上游充值和中转站调用成本不应直接相加为“总成本”。它们来自不同账本或远端接口，可能存在渠道映射不完整、充值时间与实际消耗时间错位、倍率覆盖未更新等差异。

## 分析顺序

1. 确认所有账本记录关联了正确的渠道、中转站或账号。
2. 检查账号成本来源和成本采集完整性。
3. 核对中转站账号是否与监控渠道正确关联。
4. 对齐页面时间范围和服务器时区。
5. 将余额快照消耗、充值账本和调用成本分开比较，再解释差异。
