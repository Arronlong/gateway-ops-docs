# 风险与调度概览

账号风险比较当前成本倍率与销售分组倍率，用于给出调组建议；它不是现金利润审计。成本来源及覆盖优先级见 [成本与倍率](/logic/cost-accounting)。

## 状态如何区分

| 状态 | API 值 | 判断含义 |
| --- | --- | --- |
| 账号未启用 | `inactive` | 账号不是 `active`，不继续判定调组风险。 |
| 成本未知 | `cost_unknown` | 没有有效且明确来源的成本。 |
| 未分配销售组 | `unassigned` | 没有启用、平台一致、类型兼容的有效当前组。 |
| 分组安全 | `protected` | 有效当前组均有正向倍率空间。 |
| 无利润 | `no_profit` | 当前组含倍率与成本相等的组，没有亏损组。 |
| 亏损风险 | `risk` | 当前至少一个有效组倍率低于成本，且有盈利候选。 |
| 无安全候选 | `no_safe_candidate` | 当前存在亏损组，缺少符合条件的盈利候选。 |

状态按当前快照计算，先判断账号、成本和有效当前组，再判断倍率关系。候选有自己的平台、类型、模型条件，普通手动建议与自动建议不能完全等同。

## 哪些配置会修改什么

| 配置 / 操作 | 修改对象 | 规则 |
| --- | --- | --- |
| 亏损 / 无利润自动调组 | 远端账号组关联，特定情况关闭调度。 | [自动调组](/logic/auto-group-adjustment) |
| 自动优先级与召回 | 远端账号优先级。 | [自动优先级与召回](/logic/auto-priority) |
| 手工成本覆盖、模型绑定 | 本地规则，供后续风险与成本计算使用。 | [成本与倍率](/logic/cost-accounting) |
| 手动并发、重试、调度开关 | 远端运行配置。 | [账号操作与测试](/logic/account-operations) |

自动调组、无利润调组、自动优先级及召回内置默认均关闭。自动调组由快照同步或倍率同步成功后的阶段触发，自动优先级只由快照同步触发；不是设置一保存就对所有账号立即执行。

调组与优先级使用不同算法；暂停调度后没有自动恢复逻辑。调整记录用于查明已发生的修改，但批量操作允许部分成功。排查先看成本与快照时间，再看模型绑定、开关及执行结果。
