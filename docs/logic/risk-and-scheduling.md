# 风险与自动调度

风险判断比较账号成本倍率与当前销售分组倍率，并根据平台、账号类型和可用状态寻找可盈利候选组。风险状态是运营判断信号，不等同于真实利润审计。

## 成本倍率来源

账号成本可从同步的成本字段取得，也可由手工覆盖、渠道分组或自动关联提供。若账号成本缺失、无效或没有明确来源，系统标为“成本未知”，不会把上游对象默认的倍率当作零成本或有效成本。

## 风险状态

| 状态 | 当前判断含义 |
| --- | --- |
| 账号未启用 | 远端账号当前不是启用状态，不继续计算调组风险。 |
| 成本未知 | 没有有效且明确来源的账号成本倍率。 |
| 未分配销售组 | 没有匹配平台和账号类型的有效当前销售组。 |
| 分组安全 | 当前有效分组倍率高于账号成本，且没有触发亏损或无利润状态。 |
| 无盈利候选 | 存在与成本相等、没有正向空间的当前分组；仍需查看是否有其他建议分组。 |
| 亏损风险 | 至少一个当前有效销售分组倍率低于账号成本。 |
| 无安全候选 | 当前分组存在亏损风险，但没有满足基本条件的有效盈利候选分组。 |

状态判定先检查账号和成本是否有效，再检查当前分组；候选分组必须启用、平台一致、账号类型兼容，并且销售倍率高于账号成本。模型类型限制会进一步影响自动调组和可降级候选。

## 调组建议

当当前分组存在亏损或无利润组时，系统按候选组倍率从低到高选择满足盈利条件的分组，并结合账号当前已分配组生成建议。推荐结果是根据当前快照和倍率生成，不保证上游价格或账号成本在执行后不变。

手工应用建议和自动调组都会更新 Sub2API 账号分组，并写入调整记录。批量操作可能部分成功；完成后检查成功数、失败账号和审计记录。

## 可降级提示与优先级

可降级提示用于找出比当前销售倍率更低、但仍高于账号成本的分组。自动调组候选与可降级提示并非完全相同的筛选逻辑；模型类型配置会限制相关候选。

流畅度自动排序根据近期首字时间和总耗时调整 API Key 优先级。当前规则中 OAuth 账号固定使用优先级 1；未调用或较快的 API Key 从优先级 2 起排序，较慢者依次降低。优先级数值越小越优先。网络抖动、样本不足和上游状态变化都可能影响排序结果。

## 风险和利润不是一回事

账号行中的利润率说明采用：

```text
利润率 = (销售倍率 - 成本倍率) ÷ 成本倍率
```

风险状态关注当前销售分组是否覆盖账号成本；成本管理的实时倍率使用的是全局支出、当前渠道余额和用户扣费。两者维度和计算方式不同，不能互换。

在执行自动调组、自动优先级或自动停用前，先确认成本来源、销售分组适配范围、账号模型类型和当前快照时间。建议先观察手工建议与调整日志，再启用自动策略。
