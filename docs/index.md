# GatewayOps 文档

GatewayOps 是面向 NewAPI / Sub2API 生态的自托管运营管理平台。本网站说明如何部署和使用 GatewayOps，并解释页面指标、业务规则与系统架构。

如果你是第一次使用，请从 [项目概览](/start/overview) 和 [快速开始](/start/quick-start) 入手。已经在运行 GatewayOps 的用户可以直接查阅 [产品使用指南](/guide/dashboard) 或 [业务规则与指标](/logic/metrics)。

文档中的产品功能和规则以 GatewayOps 当前实现为依据。不同版本的功能可能略有差异；升级前请同时查看对应版本的发布说明。所有示例均为虚构配置，不代表真实环境。
